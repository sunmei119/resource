一、文档概述

一 文档概述

本 PRD 基于 design.md 展开研发可评审的详细需求说明，覆盖资源中心管理后台一期"类目管理"下的频道管理、分类管理、条目管理三类子模块、"资源管理"下的资源列表子模块，以及"硬件与服务管理"下的智慧硬件与服务、预约记录两类子模块，共 11 个页面。字段、权限、状态以 design 为唯一事实源，本 PRD 只做交付镜像与规格展开。

二 范围

  • 一期页面：频道列表页、频道新增/编辑页、分类列表页、分类新增/编辑页、条目管理·分类管理 Tab、条目管理·分类条目管理 Tab、资源列表页、资源新增/编辑页、智慧硬件与服务列表页、硬件/服务新增/编辑页、预约记录列表页
  • 一期角色：后台管理员（单一角色，无字段级权限例外）
  • 不做：登录、权限模块、对外接口契约

三 业务流程

管理员按"父频道 → 子频道 → 分类 → 维度配置"顺序搭建类目体系，最终通过上架把类目下发给已有应用端消费。

1
管理员创建父频道，通过"是否在资源中心展示"字段决定该父频道是否在资源中心露出；根据需要在父频道下新增子频道（层级最多两级，子频道不可再挂子频道）。
2
管理员在子频道下创建一级分类与子分类，分类完成上架后应用端可获取；新增与编辑一级分类时按所属子频道列出的全部类目逐类目勾选类目条目，勾选条目后若该条目下存在已上架子条目，展示对应子条目并可继续勾选（所属频道下存在已上架类目条目时展示该字段且为必填；无任何类目条目时不展示"类目条目"字段）；新增/编辑子分类（二级）时仅挂靠父分类，无需关联类目条目。
3
管理员在"条目管理·维度配置"中按"所属频道"（级联到子频道）维护分类维度与维度条目，维度条目完成上架后应用端按配置动态渲染筛选视图。
4
管理员在"资源管理·资源列表"中通过三步式表单新增资源（基本信息 / 资源正文 / 发布设置），资源的"所属频道"通过级联父频道→子频道选择，选定"所属分类"后可按该分类所在子频道勾选项下的类目条目（分类已关联的条目默认勾选且只读）；资源正文需设定"收费方式"（免费 / 收费，默认免费），收费时展示权益（数字输入 + 单位 天/次，选填，不受内容展示方式限制，留空表示不限制权益），收费且内容展示方式非"应用和链接"时还需补充应用选择，PC端链接与移动端链接为选填；可选择"提交"（未发布）或"提交并发布"（已发布）；提交时系统先对资源标题、简介、正文执行机器敏感词过滤，通过则允许发布、命中违规词则不可发布，仅可以"未发布"状态保存并提示修改；列表支持上架、下架、编辑、删除、预览、设为推荐/取消推荐（仅已发布），其中编辑与删除仅在资源为"未发布"时展示（已发布需先下架），勾选多行后支持批量上架、批量下架、批量推荐、批量取消推荐、批量删除。
5
管理员在"硬件与服务管理·智慧硬件与服务"中维护智慧硬件与定制服务：按名称、频道、分类、状态查询；通过"硬件/服务新增/编辑页"（独立页面）新增或编辑（名称、类型、所属频道、所属分类、排序、背景色、字体颜色、简介、详细介绍、详细介绍图片、附件上传），新增保存后状态为"未发布"；列表行支持发布、下架、编辑、删除（已发布不可删），勾选多行后支持批量发布、批量下架；应用端用户对已发布的硬件/服务提交预约后，记录进入"预约记录"，管理员可查询、查看详情并受理或取消。
条目管理·维度配置能力：管理员在"条目管理·分类管理 Tab"定义分类维度（如"学段""年级""学科"），在"分类条目管理 Tab"为每个维度维护维度条目（如"学段"下的"小学""初中""五四制"）。应用端拉取分类维度、维度条目两份配置后自动渲染筛选行，无需改代码。

关键分支与约束

  • 频道被任意分类引用后不可删除；父频道下存在子频道时不可删除，需先删除全部子频道；分类在"已上架"状态下不可删除，需先下架。
  • 分类的上架、下架、删除均需二次确认，确认后同步至应用端可见性契约。
  • 分类维度删除前需先清空维度下的维度条目。
  • 智慧硬件与服务在"已发布"状态下不可删除，需先下架；发布、下架、批量发布、批量下架均需二次确认；下架不影响已产生的预约记录。
  • 预约记录由应用端提交，后台不支持新增与删除，仅可查看、受理、取消。

四 详细需求说明

（一）频道管理模块

本模块负责频道的创建、维护与展示开关，涉及频道列表页、频道新增/编辑页。分类与条目均依赖频道数据。

频道列表页

页面由顶部筛选栏、主列表和右上角"新增父频道"入口组成，管理员在此完成对全量频道（含父/子两级）的查看、检索与增删改操作。

（1）查询频道

管理员进入页面后默认加载全量频道列表，用于确认当前资源中心的顶层入口结构。筛选栏支持按"频道名称"（文本，模糊匹配）与"是否在资源中心展示"（下拉：全部/是/否）过滤。

  1. 修改筛选条件后点击"查询"，列表按当前条件刷新并回到第 1 页。
  2. 点击"重置"，筛选项清空并重新加载第 1 页。
  • 列表按"排序"字段升序展示，排序值相同时按"修改时间"倒序作为二级排序键。
  • 每页 20 条，底部提供分页控件。
  • 无匹配数据时列表区域展示"暂无频道，请点击右上角新增"。
  • 查询失败时列表区域展示"加载失败，请重试"并提供"重试"入口。

（2）新增父频道

点击列表右上角"新增父频道"按钮，打开新增页。表单初始化为空，"父频道"字段不出现（新增父频道场景），"是否在资源中心展示"默认选中"是"，"排序"默认空需管理员填写。保存成功后弹窗关闭，列表按当前筛选条件刷新并定位到新增记录所在页。保存失败时保留当前输入并在弹窗顶部提示后端返回的错误信息。

（2.1）添加子频道

在父频道行行尾点击"添加子频道"按钮，打开新增子频道态。"所属父频道"字段默认带出当前父频道，并提供父频道下拉列表，支持修改为其它父频道；其余字段与新增父频道一致（频道图片除外：新增子频道时频道图片选填、大小 ≤5M；父频道新增/编辑仍为必填、≤300KB），"是否在资源中心展示"默认"是"；并额外展示"跳转设置"分组："跳转方式"单选、必填、默认"内部跳转"，按所选方式联动展示对应字段（详见下方频道新增/编辑页字段说明）。子频道行不展示该动作。保存成功后列表刷新并定位到新增子频道，子频道以"└"缩进标记在父频道下。

（3）编辑频道

点击某行行尾"编辑"按钮，以该行数据初始化编辑页。所有字段可编辑，"频道图标""频道图片"支持替换重新上传；若该记录为子频道，"所属父频道"字段按当前值带出并可重新选择其它父频道（下拉可改），并回填该子频道的跳转设置（跳转方式、应用名称、PC端/移动端跳转地址或目标地址），可重新修改。父频道不展示跳转设置字段。保存成功后弹窗关闭并刷新列表，保存失败提示同新增。

（4）删除频道

单条删除：点击行尾"删除"按钮，弹出二次确认框，标题为"确认删除频道？"，正文提示"删除后不可恢复。已被分类引用的频道不允许删除；父频道下存在子频道时不允许删除，请先删除全部子频道。"确认后调用后端删除接口。

批量删除：勾选列表左侧复选框，点击列表顶部"批量删除"按钮，弹出二次确认框，正文提示删除条数与"已被分类引用的频道、或下属存在子频道的父频道将不被删除"的口径。确认后后端逐条判断：可删除项直接删除，不可删除项在结果提示中列出频道名称。

  • 已被任意分类引用的频道，后端返回禁止删除错误，前端提示"频道 X 已被分类引用，不可删除"。
  • 父频道下存在子频道时，后端返回禁止删除错误，前端提示"父频道 X 下存在子频道，请先删除全部子频道"（R-DEL-01）。
  • 删除请求进行中时按钮进入加载态并置灰，防止重复提交。
  • 网络异常时提示"删除失败，请检查网络后重试"，列表状态保持不变。

（5）展示字段说明

列表展示：采用树形展示（与分类列表一致）——父频道为一级节点，其子频道作为下级节点以缩进+展开标识挂在父频道之下，父子行相邻呈现。列展示：频道图标（缩略图，点击可查看大图）、频道名称（树形缩进展示，父频道行带展开标识、子频道行缩进）、是否在资源中心展示（是/否标签）、频道描述、排序、修改时间（YYYY-MM-DD HH:mm:ss）、操作列（编辑、添加子频道（仅父频道行）、删除）。

  • 频道描述超过一行时末尾截断，悬停显示完整内容。
  • 频道图标加载失败时占位显示默认图标。

频道新增/编辑页

弹窗或抽屉形式承载表单，管理员在此完成频道的字段录入或修改，字段与规则新增编辑一致。

（1）填写频道信息

表单按信息分组展示：

  • 归属信息：所属父频道（新增子频道时默认带出当前父频道并提供父频道下拉列表，支持修改为其它父频道；新增父频道时该字段不出现；编辑子频道时按当前值带出，同样支持下拉修改）
  • 基本信息：频道名称（单行文本）、频道图标（图片选择器，尺寸 68×68，大小 ≤100KB）、频道图片（图片选择器；父频道必填、大小 ≤300KB；子频道选填、大小 ≤5M）、是否在资源中心展示（单选，"是/否"，默认"是"）、排序（数字输入，非负整数）。父/子频道均必填的为：频道名称、频道图标、是否在资源中心展示、排序
  • 跳转设置（仅子频道展示，新增子频道与编辑子频道均展示；父频道不展示）：跳转方式（单选，必填，默认"内部跳转"，可选"内部跳转 / 应用 / 外部链接"），并按所选方式联动展示：
跳转方式展示字段必填说明
内部跳转PC端跳转地址、移动端跳转地址否文本输入；不填时默认跳转到该子频道对应界面；填写后跳转到对应内部地址
应用应用名称、PC端目标地址、移动端目标地址应用名称必填；目标地址选填应用名称为可搜索输入框，按应用名称模糊查询，最多查询 50 条数据；目标地址文本前缀为 https:// 或 http://
外部链接PC端目标地址、移动端目标地址是文本输入，文本前缀为 https:// 或 http://

切换跳转方式时，按新方式重置并展示对应字段，原方式下填写的地址不清空但不再参与校验与提交。

字段校验规则：

  • 频道名称：必填，最长 20 字符，超过 20 字符输入被截断并提示"最多输入 20 个字符"。
  • 频道图标：必填，尺寸不满足 68×68 时提示"图标尺寸需为 68×68 像素"；大小超 100KB 时提示"图标大小不得超过 100KB"。
  • 频道图片：父频道（新增/编辑父频道）必填，大小超 300KB 时提示"图片大小不得超过 300KB"；子频道（新增/编辑子频道）选填，可不上传，上传时大小超 5M 时提示"图片大小不得超过 5M"。
  • 是否在资源中心展示：必填，默认"是"，新增时若管理员未选择保存按钮不可点击。
  • 排序：必填，非负整数，为空时提示"请输入排序值"；输入负数或非整数时提示"排序需为非负整数"。
  • 频道描述：选填，超 200 字符输入被截断并提示"最多输入 200 个字符"。
  • 跳转方式：子频道必填，默认"内部跳转"，未选择时保存按钮不可点击。
  • 应用名称：跳转方式=应用时必填，未选择时提示"请选择应用名称"；支持输入关键字模糊查询，单次最多返回 50 条匹配数据。
  • PC端目标地址 / 移动端目标地址：跳转方式=外部链接时必填，为空时提示"请输入目标地址"；跳转方式=应用时选填。
  • 目标地址格式：跳转方式为应用或外部链接时，地址须以 https:// 或 http:// 开头，前缀由下拉选择（默认 https://）；不满足时提示"目标地址需以 http:// 或 https:// 开头"。
  • 内部跳转地址：跳转方式=内部跳转时选填，不填则应用端默认跳转到该子频道界面。

（2）保存频道

校验时机：字段失焦时对当前字段做即时校验；点击"保存"时对全部必填字段做一次整体校验。校验全部通过后按钮进入加载态显示"保存中..."并防止重复点击，后端返回成功后弹窗关闭、列表刷新并定位到新增或编辑记录；后端返回失败则在弹窗顶部展示错误信息且表单保留当前输入。保存过程中关闭弹窗触发确认框"当前修改尚未保存，确认关闭？"，管理员确认后丢弃输入。网络异常时提示"保存失败，请检查网络后重试"。

（二）分类管理模块

本模块负责分类和子分类的创建、维护与上下架，涉及分类列表页、分类新增/编辑页。分类依赖频道数据。

分类列表页

页面以树形结构承载分类和子分类，顶部为筛选栏，主体为可展开/收起的树形列表，右上角提供"新增一级分类"入口。

（1）查询分类

筛选栏支持按"所属频道"（级联下拉：先选父频道，再选子频道，最终按二级子频道过滤）、"分类名称"（文本，模糊匹配）、"上架状态"（下拉：全部/未上架/已上架）过滤。默认加载全部一级分类，子分类通过点击行首箭头展开。

  1. 修改筛选条件后点击"查询"，树按条件刷新，符合条件的节点自动展开到匹配节点。
  2. 点击"重置"，筛选项清空并收起所有子树。
  • 同层级按"排序"字段升序展示，排序值相同时按"修改时间"倒序。
  • 每页 20 条一级分类，底部提供分页控件。
  • 无匹配数据时展示"暂无分类，请点击右上角新增"。
  • 加载失败时展示"加载失败，请重试"。

（2）新增一级分类

点击右上角"新增一级分类"按钮进入新增页，"所属频道"必选（单个级联输入框，父频道→子频道，仅二级子频道可选中），"父分类"字段不出现；选定所属频道后，若该子频道下存在已上架类目条目，则展示"类目条目"字段并列出所有类目及类目条目供勾选（必填，须至少勾选一项后方可提交）；勾选条目后若该条目下存在已上架子条目，则展示对应子条目并可继续勾选（仅展示该条目下已上架的子条目；未勾选的条目不展示其子条目）。若该子频道下无任何类目条目，则不展示"类目条目"字段（标签与勾选区均不出现）。保存成功后树刷新并定位到新增记录，行首图标为一级节点。

（3）添加子分类

在某个一级分类或已展开的子分类行尾点击"添加子分类"按钮进入新增页，"父分类"字段自动填入当前节点并置为只读，"所属频道"自动继承父节点并置为只读；不展示类目及类目条目字段（子分类无需关联类目条目）。保存成功后自动展开父节点并定位到新增子分类。

（4）编辑分类

点击行尾"编辑"按钮以该行数据初始化编辑页。"所属频道""父分类"允许编辑（编辑时若变更所属频道，需提示"变更所属频道将同时移动其子分类，是否继续？"）；一级分类展示"类目及类目条目"项并回填已勾选类目条目及其下已勾选子条目（可继续增删），子分类不展示此字段。保存成功后按当前筛选条件刷新树。

（5）上架分类

点击行尾"上架"按钮弹出二次确认框，标题为"确认上架分类？"，正文提示"上架后应用端可获取该分类"。确认后后端更新"上架状态"为"已上架"并同步至应用端。

  • 上架成功后行状态标签由"未上架"变为"已上架"，"上架"按钮切换为"下架"按钮。
  • 上架过程中按钮进入加载态。
  • 后端返回失败时行状态保持"未上架"并提示"上架失败：<错误信息>"。

（6）下架分类

点击行尾"下架"按钮弹出二次确认框，标题为"确认下架分类？"，正文提示"下架后应用端不可获取该分类，其下已上架的条目仍保留自身上架状态，但不再随本分类下发"。确认后后端更新"上架状态"为"未上架"。

  • 下架成功后行状态标签由"已上架"变为"未上架"，按钮切换回"上架"。
  • 下架失败时状态保持不变并提示"下架失败：<错误信息>"。

（7）删除分类

单条删除：点击行尾"删除"按钮，弹出二次确认框"确认删除分类？删除后不可恢复。已上架分类不允许删除。"。已上架状态下"删除"按钮置灰并 hover 提示"请先下架再删除"。

批量删除：勾选左侧复选框后点击顶部"批量删除"，弹出二次确认框展示删除条数与"已上架分类将不被删除"口径。确认后后端逐条判断：已上架分类不被删除，结果提示中列出未删除项分类名称。

  • 存在子分类的一级分类被删除时，同一请求下所有后代节点一并删除，二次确认框正文追加"该分类下的所有子分类将一并删除"。
  • 删除失败时列表状态保持不变并提示错误信息。

（8）展示字段说明

树形列表展示：分类名称、分类编码（code 样式等宽字体展示）、所属频道（跨节点固定展示，展示为"父频道 / 子频道"两级名称）、上架状态（未上架灰色标签、已上架绿色标签）、分类描述（末尾截断，悬停显示全文）、排序、修改时间、操作列。

  • 树形节点默认收起至一级分类；一级分类前的展开箭头在无子分类时隐藏。
  • 单次展开的子分类总数超过 200 时提示"子分类过多，建议使用筛选缩小范围"。

分类新增/编辑页

（1）填写分类信息

表单按信息分组展示：

  • 归属信息（必填）：所属频道（单个级联输入框，交互同资源"所属分类"：先选父频道再选子频道，最终存储二级子频道ID）、父分类（新增子分类和编辑子分类时展示为只读，新增一级分类时不出现）
  • 基本信息（必填）：分类名称、分类编码、排序
  • 展示素材（选填）：分类图标、分类封面、按钮文字
  • 类目条目（仅一级/顶级分类、且所属频道下存在已上架类目条目时展示）：类目及类目条目（仅一级/顶级分类展示；按当前"所属频道"列出该子频道下所有类目及各类目条目，展示形态同资源表单——逐类目一行、条目为多选复选框；用户逐类目勾选；未选所属频道时不展示该字段。二级/子分类不展示此类目条目字段；若该所属频道（子频道）下无任何类目条目，则不展示"类目条目"字段（标签与勾选区均不出现）；仅当存在已上架类目条目时为必填，须至少勾选一项，为空提示"请选择类目及类目条目"）
  • 补充信息（选填）：分类描述

字段校验规则：

  • 所属频道：必填，为空时提示"请选择所属频道"；级联选择时必须选到二级（子频道）后方可提交（R-CH-20）。
  • 分类名称：必填，最长 20 字符。
  • 分类编码：必填，最长 10 字符，不允许输入中文，实时过滤中文字符并提示"分类编码不支持中文"。
  • 排序：必填，非负整数。
  • 分类图标：选填，图片上传（单张），格式 .jpg/.jpeg/.png，大小 ≤2MB；已上传图标可移除后重传；未上传时允许保存，应用端不展示图标位（R-CH-30）。
  • 分类封面：选填，图片上传（单张），格式 .jpg/.jpeg/.png，大小 ≤5MB；已上传封面可移除后重传；未上传时允许保存，应用端使用默认封面（R-CH-30）。
  • 按钮文字：选填，单行文本，最长 10 字符，作为应用端分类入口按钮文案；为空时应用端按钮不展示（R-CH-30）。
  • 分类描述：选填，最长 200 字符。
  • 类目及类目条目：仅一级/顶级分类展示；若该所属频道（子频道）下存在已上架类目条目则展示该字段且为必填，须至少完成勾选后方可提交，为空时提示"请选择类目及类目条目"；勾选条目后若该条目下存在已上架子条目，展示对应子条目并可继续勾选（仅展示已上架子条目）；若该子频道下无任何类目条目，则不展示该字段（标签与勾选区均不出现）；二级/子分类不展示此字段（R-CH-21）。

（2）保存分类

校验时机与保存流程与频道保存一致。变更"所属频道"提交时后端可能返回"存在编码冲突"，此时在表单顶部展示后端错误并保留当前输入。新增子分类时"父分类"和"所属频道"为只读，保存时随请求一并提交。

（三）条目管理模块

条目管理模块通过 2 个 Tab 页承载：分类管理 Tab（维护分类维度）、分类条目管理 Tab（维护维度下的条目）。两个 Tab 同居"条目管理"菜单下，管理员可在同页顶部页签切换。

条目管理·分类管理 Tab

页面由顶部筛选栏、主列表和"新增分类维度"入口组成，管理员在此完成对分类维度（左侧行标题，如"学段/年级/学科"）的增删改查。

（1）查询分类维度

管理员进入 Tab 后默认加载全部分类维度。筛选栏支持按"所属频道"（级联下拉：先选父频道，再选子频道，最终按二级子频道过滤）、"维度名称"（模糊匹配）与"上架状态"（下拉：全部/上架/下架）过滤。

  1. 修改筛选条件后点击"查询"，列表刷新并回到第 1 页。
  2. 点击"重置"，筛选项清空并重新加载第 1 页。
  • 列表按"维度排序"升序展示，排序值相同时按"修改时间"倒序。
  • 每页 20 条，底部提供分页控件。
  • 无匹配数据时展示"暂无分类维度，请点击右上角新增"。
  • 加载失败时展示"加载失败，请重试"。

（2）新增分类维度

点击"新增分类维度"按钮打开新增弹窗，表单初始化为空，弹窗不展示"上架状态"字段，新增提交后该维度默认"下架"，"维度排序"默认空。保存成功后弹窗关闭，列表刷新并定位新增记录。保存失败时保留输入并顶部提示错误信息。

（3）编辑分类维度

点击行尾"编辑"按钮，以该行数据初始化编辑弹窗，字段均可编辑。保存成功后刷新列表。

（4）批量上架 / 下架 / 删除

勾选左侧复选框后可点击顶部"批量上架""批量下架""批量删除"按钮：

  • 批量上架/下架：直接调后端更新"上架状态"，成功后刷新；失败列出失败项名称。
  • 批量删除：弹出二次确认框正文提示删除条数与"维度下存在维度条目时将不被删除"口径。确认后后端逐条判断，未删除项在结果提示中列出维度名称。

（5）删除分类维度

单条删除：点击行尾"删除"按钮，弹出二次确认框"确认删除分类维度？删除后不可恢复。维度下存在维度条目时不允许删除，请先清空关联数据"。

  • 满足删除前置约束时（无维度条目）按钮可点击，否则置灰并 hover 提示"维度下存在 X 条维度条目"。
  • 删除失败时列表状态保持不变。

字段类型规则
所属频道级联下拉（父频道→子频道）必填，选项来源频道管理接口；最终存储二级子频道ID（R-CH-22）
维度名称单行文本必填，最长 20 字符
维度排序数字输入必填，非负整数
上架状态单选（上架 / 下架）仅编辑时展示；新增时不展示该字段，提交后默认"下架"

校验规则：

  • 所属频道：必填；未选到二级子频道时提示"请选择所属频道（需级联到子频道）"
  • 维度名称：必填，最长 20 字符，超长截断并提示"最多输入 20 个字符"
  • 维度排序：必填，非负整数，输入负数或非整数时提示"排序需为非负整数"
  • 上架状态：仅编辑时展示并必填

（7）展示字段说明

列表展示：维度名称、所属频道（展示为"父频道 / 子频道"两级名称）、维度排序、上架状态（上架绿色标签、下架灰色标签）、修改时间（YYYY-MM-DD HH:mm:ss）、操作列（编辑、删除）。

  • 上架状态为"下架"时行文本置灰。

条目管理·分类条目管理 Tab

页面由顶部筛选栏、树形主列表和"新增维度条目"入口组成，管理员在此维护每个分类维度下的维度条目（如"学段"下的"小学""初中""五四制"）。维度条目以树形展示：维度条目为一级节点，可下挂子条目（二级节点，最多两层，子条目下不可再新增子条目）；子条目下以"子条目项（条目名称 + 排序 + 上架状态）"呈现叶子内容，子条目项支持上/下架与删除（已上架不可删），仅"已上架"的子条目项在应用端渲染；被其他分类引用的子条目不可删除。

（1）查询维度条目

顶部筛选栏必选"归属维度"（下拉，选项来源分类维度接口），切换归属维度后列表整表刷新展示对应维度下所有维度条目。可选"条目名称"（模糊匹配）与"上架状态"（下拉：全部/未上架/已上架）过滤。

  1. 修改筛选条件后点击"查询"，列表按当前条件刷新并回到第 1 页。
  2. 点击"重置"，"条目名称"与"上架状态"清空，"归属维度"保留（避免筛不到任何数据）。
  • 列表按"条目排序"升序展示，排序值相同时按"修改时间"倒序。
  • 每页 20 条，底部提供分页控件。
  • 未选择归属维度时列表区域展示"请先选择归属维度"。
  • 无匹配数据时展示"该维度下暂无条目，请点击右上角新增"。

（2）新增维度条目

点击"新增维度条目"按钮打开弹窗，"归属维度"自动继承筛选栏当前值并可切换；弹窗不展示"上架状态"字段，新增提交后该条目默认"未上架"。保存成功后按当前筛选条件刷新列表。

（2.1）新增子条目

在维度条目行尾点击新增子条目按钮，打开新增子条目弹窗。"当前条目名称"自动带入所属维度条目名称并置为只读；管理员填写"子条目名称"（必填，最长 20 字符）与"子条目排序"（必填，非负整数，用于子条目之间的展示顺序），并通过"新增子条目项"按钮添加若干子条目项，每项需填写"条目名称"（必填，最长 20 字符）与"排序"（必填，非负整数），上架状态默认"未上架"。保存成功后该维度条目自动展开，子条目作为二级节点呈现，子条目项在子条目下以叶子内容展示。子条目行不展示"新增子条目"按钮（仅两层，子条目下不可再新增子条目）。

（2.2）子条目上架 / 下架

子条目行提供"上架""下架"按钮（与维度条目上/下架流程一致，均弹窗二次确认）。上架成功后状态标签由"未上架"变为"已上架"，按钮切换；下架成功后反向切换。应用端筛选视图仅渲染"已上架"的子条目；上/下架失败时状态保持并顶部提示错误信息。

（3）编辑维度条目

点击行尾"编辑"按钮以该行数据初始化弹窗，"归属维度"允许切换（切换归属维度将同时移动该条目至新维度）。保存成功后刷新列表。

（4）上架 / 下架

点击行尾"上架""下架"按钮弹出二次确认框，与分类上下架流程一致。上架成功后行状态标签由"未上架"变为"已上架"，按钮切换；下架成功后反向切换。

  • 应用端筛选视图仅渲染"已上架"维度条目。
  • 上/下架失败时行状态保持并顶部提示错误信息。

（5）批量上架 / 下架 / 删除

勾选左侧复选框后可点击顶部批量按钮：

  • 批量上架/下架：二次确认后逐条更新状态，失败项在结果提示中列出。
  • 批量删除：二次确认框正文提示删除条数与"已上架或存在子条目的维度条目将不被删除"口径。

（6）删除维度条目

单条删除：点击行尾"删除"按钮，弹出二次确认框"确认删除条目？删除后不可恢复。若条目下存在子条目，则条目无法删除"。

  • 已上架状态、或条目下存在子条目时按钮置灰（分别 hover 提示"请先下架再删除"、"条目下存在子条目，无法删除"）。
  • 删除失败时列表状态保持不变。

（6.1）删除子条目

单条删除：在子条目行尾点击"删除"按钮，弹出二次确认框"确认删除子条目？删除后该子条目及其下所有子条目项将一并移除，且不可恢复。被其他分类引用的子条目不可删除。"；确认后级联删除该子条目及其下全部子条目项。

  • 已上架的子条目不允许删除，需先下架：已上架状态下"删除"按钮置灰并 hover 提示"请先下架再删除"。
  • 被其他分类引用的子条目不允许删除：被引用状态下"删除"按钮置灰并 hover 提示"该子条目已被其他分类引用，无法删除"。
  • 删除失败时列表状态保持不变。

（6.2）子条目项上/下架与删除

在子条目项行尾点击"上架/下架"按钮，二次确认后切换上架状态；仅"已上架"的子条目项在应用端筛选视图渲染。

单条删除：点击子条目项行尾"删除"按钮，弹出二次确认框"确认删除该子条目项？删除后不可恢复"。已上架的子条目项"删除"按钮置灰，需先下架方可删除。

  • 子条目项·上架状态：新增默认"未上架"，保存后可在列表中上/下架

（8）展示字段说明

列表展示：树形结构——维度条目为一级节点，其行首展开标识仅在存在子条目时显示；展开后子条目作为二级节点（缩进）呈现，子条目节点展示"子条目排序"与"上架状态"列，子条目下以"子条目项（条目名称 + 排序 + 上架状态）"展示叶子内容，子条目项行内提供上架/下架、删除操作，已上架的子条目项"删除"按钮置灰；子条目不可再下挂子条目。一级节点列：条目名称、条目排序、上架状态（未上架灰色标签、已上架绿色标签）、创建时间、修改时间、操作列（编辑、上架/下架、删除、新增子条目）；子条目节点列：子条目排序、上架状态；子条目节点操作列（编辑、上架/下架、删除）。已上架或已被其他分类引用的子条目"删除"按钮置灰：已上架需先下架，被引用需解除引用后方可删除。

（四）资源管理模块

资源管理模块通过资源列表页与资源新增/编辑页两个页面承载。资源与类目管理同为顶层模块，资源通过所属频道、所属分类挂接类目体系。

资源列表页

（1）查询资源

管理员进入页面默认加载全部资源。筛选栏支持：

  • 资源标题：单行文本，模糊匹配
  • 所属频道：级联下拉（父频道→子频道），选项来源频道管理；最终按二级子频道过滤
  • 所属分类：下拉，选项按所选子频道过滤该子频道下的分类
  • 状态：单选下拉，枚举（全部 / 未发布 / 已发布）

修改筛选条件后点击"查询"，列表刷新并回到第 1 页；点击"重置"清空筛选。

（2）列表展示

列表列：资源标题、所属频道（展示为该资源所属子频道名称）、所属分类、排序、查看次数、状态（已发布绿色标签、未发布灰色标签）、推荐（"是"展示红色"推荐"标签、"否"展示"—"）、更新时间（YYYY-MM-DD HH:mm:ss）、操作列。

排序规则：按"排序"升序，排序相同按"更新时间"倒序。分页：每页 20 条，底部分页控件可翻页。

（3）行级操作

  • 预览：点击打开资源预览（模拟应用端详情展示）。
  • 编辑：进入资源编辑页，回填三步表单数据；仅"未发布"资源展示该按钮，"已发布"资源不展示（需先下架后方可编辑）。
  • 上架：仅"未发布"资源可用，二次确认后状态置为"已发布"（须已通过机器敏感词过滤）。
  • 下架：仅"已发布"资源可用，二次确认后状态置为"未发布"，并同步将该资源"是否推荐"置为"否"。
  • 设为推荐 / 取消推荐：仅"已发布"资源展示且可点；"是否推荐=否"时显示"设为推荐"，二次确认后置为"是"；"是否推荐=是"时显示"取消推荐"，二次确认后置为"否"；未发布资源不展示该按钮。
  • 删除：仅"未发布"资源展示该按钮，二次确认后移除；"已发布"资源不展示该按钮（需先下架后方可删除）。

（4）批量操作

勾选左侧复选框（支持表头全选当前页）后可点击"批量上架""批量下架""批量推荐""批量取消推荐""批量删除"；未勾选任何行时五个批量按钮置灰不可点。

  • 批量上架：二次确认框提示所选条数；确认后将所选中的"未发布"资源状态置为"已发布"，已是"已发布"的项保持不变。
  • 批量下架：二次确认框提示所选条数；确认后将所选中的"已发布"资源状态置为"未发布"，并同步将"是否推荐"置为"否"。
  • 批量推荐：二次确认框提示所选条数，并说明其中可推荐条数（仅"已发布"）与因未上架将被跳过的条数；确认后将所选中的"已发布"资源"是否推荐"置为"是"，已是推荐的项保持不变。
  • 批量取消推荐：二次确认框提示所选条数，并说明其中当前为推荐的条数；确认后将所选中的"是否推荐=是"资源置为"否"，本就未推荐的项保持不变。取消推荐不受上架状态限制（未发布项若已是推荐，也一并置为"否"）。
  • 批量删除：二次确认框提示删除条数与"已发布资源需先下架才能删除"口径。确认后后端逐条判断，已发布项在结果提示中列出资源标题。

（5）新增资源

点击"新增资源"进入资源新增页（空表单，从步骤一开始）。

资源新增/编辑页

采用三步式表单（步骤条：基本信息 → 资源正文 → 发布设置），支持上一步/下一步切换，每步"下一步"时校验当前步必填项。

（1）步骤一：基本信息

  • 所属频道：级联下拉（父频道→子频道），必填，选项来源频道管理；最终存储二级子频道ID
  • 资源标题：单行文本，必填，最长 30 字符
  • 资源简介：多行文本，选填，最长 200 字符
  • 封面：图片选择器，选填，支持 .jpg/.jpeg/.png，建议尺寸 245×143，大小 ≤3MB
  • 所属分类：单个级联输入框，选项按"所属频道"（子频道）过滤一级分类（未选到子频道时禁用，占位符"请先选择所属频道"）。是否必填由所选"所属频道"下是否存在分类决定：该频道下存在分类时为必填，为空提示"请选择所属分类"；该频道下不存在任何分类时为非必填（占位符"该频道下暂无分类，可选填"，并在字段下方提示"该所属频道下暂无分类，此为非必填"）。切换所属频道时该字段取值清空并按新频道重新判定必填性
  • 类目及类目条目：仅在选择"所属分类"后展示；按该分类所在子频道列出全部类目及类目条目，展示形态同分类表单（逐类目一行、条目为多选复选框）；其中该分类已关联的类目条目默认勾选且只读（不可取消），其余条目可自由勾选/取消；未选所属分类时不展示（R-CH-23）
  • 排序：数字输入，必填，非负整数
  • 是否在移动端展示：开关控件，必填，默认"是"；用于控制该资源是否在移动端露出，可切换为"否"

（2）步骤二：资源正文

  • 内容展示方式：单选，必填，枚举（富文本 / 文件·视频 / 应用和链接 / 链接），切换方式时下方表单区整体切换。
  • 课时：数字输入框，非必填，支持小数点；单位下拉（分钟 / 小时），默认"分钟"，位于输入框右侧作为后缀。
  • 收费方式：单选，必填，枚举（免费 / 收费），默认"免费"。
  • 权益：数字输入框 + 单位后缀下拉，只要"收费方式=收费"即展示（不受内容展示方式限制，="应用和链接"时同样展示），选填；留空表示不限制权益，一旦填写则数值须 >0 且支持小数点，单位枚举（天 / 次），默认"天"，如"7 天"表示权益有效时长、"3 次"表示权益可用次数（R-CH-32）。
  • 购买引导（应用选择 / PC端链接 / 移动端链接）：仅当"收费方式=收费"且"内容展示方式≠应用和链接"时展示；其中"应用选择"必填，为可搜索下拉（按应用名称模糊查询，最多 50 条）；"PC端链接"与"移动端链接"为选填单行文本，最长 200 字符，作为收费资源的购买去向，未填写时应用端不给出购买跳转入口（R-CH-32）。内容展示方式="应用和链接"时不重复展示这三项，收费方式以所选应用自带的收费方式为准（R-CH-31）。

本步骤采集"收费方式"（免费 / 收费，必填，默认免费）、"权益"（数字输入框 + 单位后缀下拉"天 / 次"，收费即展示但为选填，默认单位"天"，与内容展示方式无关）与配套购买引导字段（=收费且≠应用和链接时：应用选择必填，PC端/移动端链接选填）；"付费方式 / 价格"不在新增/编辑资源时展示，后台不维护这两项，由商城/应用侧维护（详见下方门户"资源消费规则"）。

方式=富文本：

  • 内容详情：富文本编辑器，必填
  • 附件：文件上传器，选填

方式=文件·视频：

  • 是否开启小节：单选（是 / 否），必填，默认"否"
  • 添加文件：点击弹出文件上传弹窗（弹窗字段：章节名称——开启小节时显示且必填，否则不显示；文件上传——文件选择器，必填，支持 .mp4/.doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf，最多 50 个，文档 ≤50MB、视频 ≤500MB）
  • 文件列表：展示已上传文件（名称、排序、操作（删除））

方式=应用和链接：

  • 应用：应用文本框 + "选择应用"按钮（点击弹出应用列表，选择后文本框显示应用名称），必填
  • 移动端链接：单行文本，选填，最长 200 字符
  • PC端链接：单行文本，选填，最长 200 字符
  • 是否开启小节：单选（是 / 否），选填
  • 添加文件 / 文件列表：同"文件·视频"方式，可不上传文件

方式=链接：

  • 移动端链接：单行文本，必填，最长 200 字符
  • PC端链接：单行文本，必填，最长 200 字符
  • 是否开启小节：单选（是 / 否），选填
  • 添加文件 / 文件列表：同"文件·视频"方式，可不上传文件

（3）步骤三：发布设置

  • 资源来源机构：单行文本，必填，最长 30 字符
  • 资源作者：单行文本，选填，最长 30 字符

（4）提交

  • 提交：先执行机器敏感词过滤（对标题、简介、正文匹配敏感词库）；无论是否命中均允许保存，状态=未发布；命中违规词时在页面顶部提示需修改后方可发布。成功后回到资源列表并定位新记录。
  • 提交并发布：先执行机器敏感词过滤；仅当过滤通过时才允许发布，状态=已发布，成功后回到资源列表；命中违规词时不允许发布，页面顶部展示违规词列表并提示"违规资源不可发布，请修改后重试，或先'提交'保存为未发布"，此时"提交并发布"操作被拒绝。

校验时机：每步"下一步"校验当前步必填项；点击"提交"或"提交并发布"时对全部步骤必填项做整体校验，任一步不通过则跳转到对应步骤并高亮错误字段；必填校验通过后再执行机器敏感词过滤（R-PUB-05）。

（1）页面结构

  • 顶部导航：品牌标识、频道导航（首页 / AI建设者 / 课程教学 / 专题资源 / 教师成长 / 家校学思）、搜索框（按资源标题、机构、标签模糊匹配）、登录入口
  • Banner：资源中心主题横幅
  • 分类入口：五个分类快捷入口（图标 + 名称，点击进入对应分类）
  • AI建设者：推荐课程卡片区，卡片展示封面、标题、机构、阅读量、点赞数
  • 课程教学：标签切换（语文 / 信息技术 / 职业 / 美育）+ 课程卡片区，选中标签的资源排前，不足 4 条由本板块其余资源补齐
  • 专题资源 / 教师成长 / 家校学思：三个轮播板块，各含标签行与可左右滚动的课程卡片（一次展示 3 张）
  • 页脚：平台介绍、关于、帮助、联系方式

（2）卡片与数据来源

  • 卡片展示字段：封面、标题、机构、阅读量、点赞数、收费标识（收费资源展示"收费"，免费资源展示"免费"）

  • 板块归属：资源按门户板块字段归入 AI建设者 / 课程教学 / 专题资源 / 教师成长 / 家校学思 五个板块
  • 搜索：顶部搜索框输入关键字后，全站卡片按标题、机构、标签模糊过滤并即时刷新

  • 下方 Tab：

    • 视频介绍：内置视频演示播放器（封面占位、可播放 / 暂停 / 重播、进度条），右侧附视频简介与时长 / 分辨率 / 适用阶段

  • 库存与有效期：库存数 999，有效期字段由后台配置或资源字段维护；为空时展示"1 年"兜底

（5）资源查看页（富文本 / 文件·视频 / 链接 / 应用）

免费资源、已购买的收费资源点击后进入"资源查看页"（独立页面，非弹窗）；应用类资源中免费或已购买的同样进入查看页展示应用卡片，收费未购买的应用类资源进入"应用购买页"。查看页与图片板式一致：顶部面包屑 + 左侧内容主区 + 右侧附件列表。

（六）硬件与服务管理模块

硬件与服务管理模块通过智慧硬件与服务列表页、硬件/服务新增/编辑页、预约记录列表页三个页面承载，与类目管理、资源管理同为顶层模块；硬件/服务通过所属频道、所属分类挂接类目体系，预约记录由应用端用户提交后进入后台供管理员处理。

智慧硬件与服务列表页

（1）查询硬件/服务

管理员进入页面默认加载全部硬件与服务。筛选栏支持：

  • 名称：单行文本，按硬件或服务名称模糊匹配
  • 频道：级联下拉（父频道→子频道），选项来源频道管理；最终按二级子频道过滤
  • 分类：下拉，选项按所选子频道过滤该子频道下的分类
  • 状态：单选下拉，枚举（全部 / 未发布 / 已发布 / 已下架）

修改筛选条件后点击"查询"，列表刷新并回到第 1 页；点击"重置"清空筛选。

（2）列表展示

列表列：名称、类型（智慧硬件 / 定制服务，标签区分）、频道（展示为"父频道 / 子频道"）、分类、排序、查看次数、状态（"已发布"绿色标签、"已下架"灰色标签、"未发布"橙色标签）、更新时间（YYYY-MM-DD HH:mm:ss）、操作列。

排序规则：按"排序"升序，排序相同按"更新时间"倒序。

（3）新增硬件/服务

点击"新增"打开"硬件/服务新增/编辑页"（独立页面，非弹窗），字段与约束：

  • 名称：必填，单行文本，最长 30 字符
  • 类型：必填，单选（智慧硬件 / 定制服务），默认"智慧硬件"
  • 所属频道：必填，级联选择父频道→子频道，必须选到二级（子频道）
  • 所属分类：按所属频道（子频道）过滤该子频道下的分类；该频道下存在分类时必填、无分类时非必填；切换所属频道时清空已选分类
  • 排序：必填，非负整数，数值越小越靠前
  • 背景色：必填，单行文本，十六进制色值（如 #ffffff，兼容 #fff），输入合法时展示色块预览
  • 字体颜色：必填，单行文本，十六进制色值（如 #1f2329，兼容 #fff），输入合法时展示色块预览
  • 简介：必填，多行文本，最长 50 字符
  • 详细介绍：必填，多行文本，最长 200 字符
  • 详细介绍图片：必填，图片上传，支持一次上传多张，格式 .jpg/.jpeg/.png，单张 ≤10MB，已上传图片可移除
  • 附件上传：非必填，支持一次上传多个，最多 5 个，单个 ≤20MB，格式 .doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf

保存后新增记录状态为"未发布"并返回列表页；点击"取消"放弃修改返回列表页。必填项未填写、色值格式不合法、未上传详细介绍图片时不允许保存并提示具体原因。

（4）编辑硬件/服务

点击行内"编辑"打开同一页面并回填当前值（含已上传的图片与附件），保存即生效并返回列表页；编辑不改变记录状态（已发布项编辑后仍为已发布）。

（5）行级操作

  • 编辑：打开"硬件/服务新增/编辑页"，回填当前数据
  • 删除："已发布"项的删除按钮置灰不可点（需先下架）；"未发布""已下架"项可删除，二次确认后移除
  • 发布："未发布""已下架"项可用，二次确认后状态置为"已发布"，应用端可见且可预约
  • 下架："已发布"项可用，二次确认后状态置为"已下架"，应用端不再展示；已产生的预约记录保留

（6）批量操作

  • 批量发布：勾选左侧复选框（支持表头全选当前页）后点击"批量发布"，二次确认框提示所选条数；确认后将所选项状态统一置为"已发布"，其中已是"已发布"的项保持不变
  • 批量下架：勾选后点击"批量下架"，二次确认框提示所选条数；确认后将所选项状态统一置为"已下架"
  • 未勾选任何行时，批量发布、批量下架按钮置灰不可点

硬件/服务新增/编辑页

（1）页面入口

  • 列表页点击"新增"进入新增模式，页面标题为"新增硬件/服务"，字段为空（背景色默认 #ffffff、字体颜色默认 #1f2329）

  • 页面右上角提供"返回列表"，底部提供"取消"与"保存"

（2）字段与校验

字段控件必填约束
名称单行文本是最长 30 字符
类型单选是智慧硬件 / 定制服务，默认"智慧硬件"
所属频道级联是父频道→子频道，必须选到二级（子频道）
所属分类下拉条件必填按所属频道（子频道）过滤；该频道下有分类时必填，无分类时选填

  • 保存：按上表逐项校验，任一不通过时阻断保存并提示具体原因（名称 / 所属频道 / 所属分类 / 排序 / 背景色 / 字体颜色 / 简介 / 详细介绍 / 详细介绍图片）；校验通过后，新增记录写入列表首位且状态为"未发布"，编辑则更新当前记录，两者保存后均返回列表页
  • 取消 / 返回列表：放弃本次修改，回到智慧硬件与服务列表页

  • 详细介绍图片单张超过 10MB、附件单个超过 20MB 或附件超过 5 个时，上传被拒绝并提示限制说明
  • 色值不合法（如 ffffff、#12345）时色块不预览，保存被阻断并提示"请输入 #ffffff 形式的十六进制色值"

七 状态机

（一）分类状态机

  • 状态集合："未上架"、"已上架"
  • 迁移：
    • "未上架" → "已上架"：管理员在分类列表页触发"上架"动作 + 二次确认；后端写入并同步应用端
    • "已上架" → "未上架"：管理员在分类列表页触发"下架"动作 + 二次确认；后端写入并同步应用端
  • 限制："已上架" 状态下禁止删除，需先下架

（二）频道

无上下架状态机；仅通过"是否在资源中心展示"字段（"是" / "否"）由管理员在频道新增/编辑页直接维护，保存生效。

（三）维度条目状态机

  • 状态集合："未上架"、"已上架"
  • 迁移：
    • "未上架" → "已上架"：管理员在分类条目管理 Tab 触发"上架"动作 + 二次确认；后端写入并同步应用端；应用端筛选视图开始渲染该条目
    • "已上架" → "未上架"：管理员在分类条目管理 Tab 触发"下架"动作 + 二次确认；后端写入并同步应用端；应用端筛选视图不再渲染该条目
  • 限制：无删除前置约束（已上架状态下禁止删除已由分类相同规则覆盖）

（四）分类维度上架状态

  • 二值字段："上架" / "下架"，新增默认"下架"（新增弹窗不展示上架状态字段，编辑时可改）
  • 由管理员在分类管理 Tab 新增/编辑弹窗直接维护，或通过列表行的上架/下架、批量上架/下架动作切换
  • "下架"状态下应用端不再渲染该维度的筛选行，但配置保留
  • 限制：维度下存在维度条目时禁止删除，需先清空关联数据

（五）资源状态机

  • 状态集合："未发布" / "已发布"，默认"未发布"
  • 迁移：
    • 未发布 → 已发布：管理员在资源新增/编辑页点击"提交并发布"，或在资源列表点击"发布"（二次确认）；成功后应用端可获取。前置约束：资源标题、简介、正文必须通过机器敏感词过滤（R-PUB-05），命中违规词时该迁移被拒绝
    • 已发布 → 未发布：管理员在资源列表点击"下架"（二次确认）；成功后应用端不再获取
  • 初始：新增资源点击"提交"进入"未发布"；点击"提交并发布"直接进入"已发布"（须先通过机器敏感词过滤）
  • 限制："已发布"状态下禁止删除，需先下架为"未发布"；"未发布"状态下可删除

（六）智慧硬件与服务状态机

  • 状态集合："未发布" / "已发布" / "已下架"，默认"未发布"
  • 迁移：
    • 未发布 → 已发布：管理员在智慧硬件与服务列表点击"发布"，或勾选多行点击"批量发布"（二次确认）；成功后应用端可获取并可预约
    • 已下架 → 已发布：同"发布"与"批量发布"动作（二次确认）
    • 已发布 → 已下架：管理员点击"下架"或"批量下架"（二次确认）；成功后应用端不再展示，已产生的预约记录保留
  • 初始：新增保存后进入"未发布"；编辑保存不改变状态
  • 限制："已发布"状态下禁止删除，需先下架为"已下架"；"未发布""已下架"状态下可删除

（七）预约记录状态机

  • 状态集合："待处理" / "已受理" / "已完成" / "已取消"，默认"待处理"
  • 迁移：
    • 待处理 → 已受理：管理员在预约记录列表点击"受理"（二次确认）
    • 待处理 / 已受理 → 已取消：管理员点击"取消"（二次确认）
    • 已受理 → 已完成：线下服务完成后由系统或管理员标记
  • 初始：应用端用户提交预约后进入"待处理"
  • 限制：预约记录不可删除
