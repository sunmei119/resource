一、文档概述

一 文档概述

本 PRD 对应 [设计基线](file:///d:/claudeCode/AIProject/ShitPM2/output/design/design.md)，将"资源中心管理后台"一期建设的设计事实展开为研发可评审的人读规格说明。范围覆盖类目管理、资源管理、审批管理、硬件与服务管理四个后台模块，以及资源中心门户前台展示端。

本文档的字段、权限、状态边界均以设计基线为唯一事实源，不新增、不改写设计已确认的定义。数据字典、权限汇总、状态机分别是对设计基线对应章节的交付镜像，不承担新的主定义职责。

二 范围

  • 建设方式：new_build（全新建设后台侧，数据侧需兼容已有应用端消费的类目数据）。
  • 角色：桂教通超管（全功能、全量数据）、后台配置人员/机构人员（受限，仅本人创建的资源与本人发起的审批数据）。
  • 一期范围：
  • 类目管理：频道管理、分类管理、条目管理（仅桂教通超管可见）。
  • 资源管理：资源列表（全角色可见，后台配置人员仅限本人创建数据）。
  • 审批管理：审批列表（全角色可见，后台配置人员仅限本人发起数据）。
  • 配置管理：后台人员配置（仅桂教通超管可见，配置哪些人员可进入资源后台及其可配置频道）。
  • 硬件与服务管理：智慧硬件与服务、预约记录（仅桂教通超管可见）。
  • 资源中心门户：前台展示端，仅展示已发布资源，不受后台角色区分影响。
  • 明确不做：登录、对外接口契约（对外接口由后端团队独立设计，本文档仅约定契约点）。

三 业务流程

3.1 类目搭建流程

桂教通超管维护四层类目体系：先创建父频道并按需下挂子频道（最多两级），再在子频道下创建一级分类并关联该子频道下已有的类目及类目条目，最后在"条目管理"中按子频道维护分类维度与维度条目。分类与维度条目上架后应用端才可获取；分类维度与维度条目均上架后，应用端才展示对应的筛选视图。全流程仅桂教通超管可操作。

3.2 资源发布与审批流程

资源发布存在两条角色路径：

  • 桂教通超管路径：新增资源可"保存草稿""提交""提交并发布"；"提交"后资源状态为未发布，"提交并发布"或列表"发布"后为已发布。超管新增资源无需审批。
  • 机构人员路径：新增资源可"保存草稿""提交"；"提交"须机器敏感词过滤通过，资源状态置为未审批并自动生成一条审批记录。桂教通超管在审批列表审批：通过则资源自动变为已发布，驳回则资源变为已驳回，机构人员可修改后重新提交（复用同一条审批记录，状态回到未审批）。

资源进入已发布状态前须通过机器敏感词过滤（对标题、简介、正文匹配敏感词库）。

3.3 硬件与服务发布流程

桂教通超管新增硬件/服务，保存后状态为未发布；发布后应用端可获取并可预约，下架后应用端不再展示但已产生的预约记录保留。应用端用户对已发布硬件/服务提交预约，预约数据进入"预约记录"，超管按状态受理或取消。

3.4 后台人员配置流程

桂教通超管在配置管理中维护后台访问人员：新增时先选所属机构（可搜索下拉），再在该机构人员中搜索选择姓名（选项展示"姓名/手机尾号4位(部门)"并带姓氏头像），选中后自动带出手机号（必填、只读）与部门；至少勾选 1 个可配置频道，其后台可见与可操作的频道数据以勾选范围为准；新增提交后状态固定为"启用"。人员登录后系统根据后台人员配置列表判定权限：配置内人员菜单权限=资源列表+审批列表，数据范围=仅本人创建的资源与本人发起的审批数据（R-CFG-04）。人员停用或删除后立即失去资源后台访问能力，启用后恢复。

四 详细需求说明

本章按设计基线模块顺序展开，页面编号与设计基线页面清单一致。各列表页共用同一套排序规则：同层级按排序值升序，排序值相同时按修改时间倒序；删除约束规则在各删除动作中逐条写清不可删条件与提示方式。

（一）类目管理

类目管理统一维护频道、分类、分类维度与维度条目四层类目体系，为应用端提供上架后的稳定类目数据；仅桂教通超管可见，机构人员不可见该菜单。涉及页面：P01 频道列表页、P02 频道新增/编辑页、P03 分类列表页、P04 分类新增/编辑页、P07 条目管理·分类管理 Tab、P08 条目管理·分类条目管理 Tab。

频道列表页

频道列表以树形结构展示父频道与子频道（最多两级），支持按频道名称与"是否在资源中心展示"筛选，提供新增父频道、编辑、添加子频道、删除与批量删除。

（1）查询频道

  • 筛选条件：频道名称（文本输入，模糊匹配）、是否在资源中心展示（下拉，是 / 否）。
  • 列表树形展示：父频道行可展开显示其子频道，子频道行首缩进并带展开标识；列包括频道图标、频道名称、是否在资源中心展示、频道描述、排序、修改时间。
  • 同层级按"排序"升序展示，排序值相同时按"修改时间"倒序展示。
  • 列表分页展示；无数据时显示"暂无频道数据"。

（2）新增父频道

  • 点击"新增父频道"打开频道新增/编辑页，进入新增父频道模式，此时"所属父频道"字段隐藏。
  • 保存成功后返回列表，新频道以父频道行加入树形结构。

（3）编辑频道

  • 行级"编辑"打开频道新增/编辑页并回填当前值。
  • 保存后列表刷新该行。

（4）添加子频道

  • 仅父频道行展示"添加子频道"，子频道行不展示该动作。
  • 点击后打开频道新增/编辑页，并默认带出当前父频道，用户可改为其他父频道。

（5）删除频道 / 批量删除

  • 行级"删除"与顶部"批量删除"均需弹窗二次确认。
  • 删除前逐条校验：已被任意分类引用的频道不可删除；为父频道且下属存在子频道时不可删除，需先删除全部子频道。
  • 含不可删项时，弹窗提示不可删原因并中止该条；批量删除逐条判断，仅删除满足条件的行。
  • 删除成功后该频道从树中移除。

频道新增/编辑页

频道新增/编辑页以弹窗/抽屉承载，新增与编辑字段一致；新增子频道时默认带出所属父频道，编辑时按当前值回填。页面按"归属信息、基本信息、跳转设置、补充信息"组织。

（1）填写归属信息

  • "所属父频道"：新增子频道时默认带出当前父频道并提供父频道下拉列表，支持改为其他父频道；新增父频道时该字段隐藏；编辑时按当前值带出并可重新选择。
  • 父频道层级约束：子频道的父频道必须指向一个已存在且"父频道"为空的父频道；子频道不允许再被选作父频道。

（2）填写基本信息

  • 必填字段：频道名称（最长 20 字符）、频道图标（68×68 px、≤100KB）、是否在资源中心展示（单选，默认"是"）、排序（非负整数）。
  • 频道图片：父频道必填、大小 ≤300KB；子频道选填、大小 ≤5M，新增/编辑子频道时均可不上传。
  • 频道描述选填，最长 200 字符，多行文本。

（3）配置跳转设置（仅子频道展示）

  • 父频道不展示本区块；子频道必填跳转方式。
  • "跳转方式"单选，默认"内部跳转"，枚举：内部跳转 / 应用 / 外部链接。
  • 跳转方式=内部跳转：展示"PC端跳转地址""移动端跳转地址"，选填，不填时应用端默认跳转到该子频道界面。
  • 跳转方式=应用：展示"应用名称"（可搜索输入框，按名称模糊查询，最多返回 50 条，必填）、"PC端目标地址""移动端目标地址"（选填，https/http 前缀）。
  • 跳转方式=外部链接：展示"PC端目标地址""移动端目标地址"（必填，https/http 前缀，前缀由下拉选择，默认 https://）。

（4）保存

  • 保存前校验上述必填字段与格式；不通过时定位首个错误字段并提示，不提交。
  • 校验通过后保存并关闭弹窗/抽屉，返回列表；列表按最新值刷新。

分类列表页

分类列表以树形结构展示一级分类与子分类，支持按所属频道、分类名称、上架状态筛选，提供新增一级分类、编辑、添加子分类、上架、下架、删除与批量删除。

（1）查询分类

  • 筛选条件：所属频道（级联选择父频道→子频道）、分类名称（文本输入，模糊匹配）、上架状态（下拉，未上架 / 已上架）。
  • 列表树形展示：列包括分类名称、分类编码、所属频道、上架状态、分类描述、排序、修改时间；同层级按排序升序、排序相同时按修改时间倒序。
  • 列表分页展示；无数据时显示"暂无分类数据"。

（2）新增一级分类 / 添加子分类

  • "新增一级分类"打开分类新增/编辑页（新增一级分类模式）。
  • 行级"添加子分类"打开分类新增/编辑页并带出当前分类为父分类（只读）。

（3）上架 / 下架

  • 行级"上架""下架"均需弹窗二次确认。
  • 上架成功后该分类应用端可获取；下架成功后应用端不可获取。
  • 上架/下架动作驱动"上架状态"字段变更，不改变其他字段。

（4）删除分类 / 批量删除

  • 行级"删除"与顶部"批量删除"均需弹窗二次确认。
  • 删除前逐条校验：处于"已上架"状态的分类不可删除，需先下架；批量删除逐条判断。
  • 删除成功后该分类从树中移除。

分类新增/编辑页

分类新增/编辑页以弹窗/抽屉承载，支持新增一级分类、新增子分类与编辑已有分类。字段按"归属信息、基本信息、展示素材、类目条目、补充信息"组织。

（1）填写归属信息（必填）

  • "所属频道"：单个级联输入框（父频道→子频道），须选到子频道，最终存储二级（子频道）的频道ID。
  • "父分类"：新增子分类时为已选定父分类，只读；编辑时按当前值展示；新增一级分类时为空。

（2）填写基本信息（必填）

  • 分类名称：最长 20 字符。
  • 分类编码：不允许中文，最长 10 字符。
  • 排序：非负整数。

（3）填写展示素材（选填）

  • 分类图标：单张，.jpg/.jpeg/.png，≤2MB；未上传时应用端不展示图标位。
  • 分类封面：单张，.jpg/.jpeg/.png，≤5MB；未上传时应用端使用默认封面。
  • 按钮文字：最长 10 字符；为空时按钮不展示（或由应用端取兜底文案）。

（4）关联类目及类目条目（仅一级/顶级分类展示）

  • 仅当"所属频道"（子频道）下存在已上架类目条目时展示本字段，且为必填（须至少勾选一项）。
  • 按"所属频道"列出该子频道下所有类目（分类维度）及各类目下的类目条目，展示形态同资源表单，用户逐类目勾选。
  • 勾选条目后若该条目下存在已上架子条目，展示对应子条目并可继续勾选（仅展示已上架的子条目；未勾选的条目不展示其子条目）；子条目选择随条目一并落存。
  • 类目本身作为层级不落存，仅存已勾选的维度条目集合。
  • 该子频道下无任何类目条目时不展示本字段（标签与勾选区均不出现）；二级/子分类不展示本字段。

（5）保存

  • 保存前校验必填字段；"类目及类目条目"为空时提示"请选择类目及类目条目"。
  • 校验通过后保存并关闭弹窗/抽屉，返回列表。

条目管理·分类管理 Tab

分类管理 Tab 承载自定义分类维度（如学段、年级、学科）的维护：查询、新增、编辑、上架/下架、批量上架/下架/删除。

（1）查询分类维度

  • 筛选条件：所属频道（级联选择父频道→子频道）、维度名称（文本输入，模糊匹配）、上架状态（下拉，上架 / 下架）。
  • 列表列：维度名称、所属频道、维度排序、上架状态、修改时间；按维度排序升序、相同时按修改时间倒序。
  • 无数据时显示"暂无分类维度数据"。

（2）新增分类维度

  • 点击"新增分类维度"打开新增弹窗：所属频道（级联选择父频道→子频道，选到子频道，必填）、维度名称（最长 20 字符）、维度排序（非负整数）。
  • 新增弹窗不展示上架状态，提交后默认"下架"。
  • 保存后新维度加入列表，上架状态为"下架"。

（3）编辑分类维度

  • 行级"编辑"打开编辑弹窗回填；编辑时可改上架状态。
  • 保存后列表刷新该行。

（4）上架 / 下架 / 批量上架 / 批量下架

  • 上架/下架均需弹窗二次确认；上架后应用端恢复渲染该维度，下架后应用端不再渲染但配置保留。
  • 批量上架/批量下架对勾选维度集合生效，均需二次确认。

（5）删除 / 批量删除

  • 删除前逐条校验：维度下存在任意维度条目时不可删除，需先清空关联数据。
  • 删除均需弹窗二次确认；批量删除逐条判断。

条目管理·分类条目管理 Tab

分类条目管理 Tab 按分类维度筛选并维护维度条目：树形展示（维度条目→子条目，最多两层）、新增/编辑维度条目、上/下架、批量上/下架/删除、新增子条目、子条目上/下架、子条目项上/下架。

（1）筛选与树形展示

  • 顶部"归属维度"必选，切换后列表整表刷新，展示对应维度下所有条目；另可按条目名称、上架状态筛选。
  • 树形展示：维度条目为一级节点；存在子条目时展开显示二级"子条目"节点，子条目下以"子条目项（条目名称 + 排序 + 上架状态）"呈现叶子内容；仅两级，子条目下不可再新增子条目。
  • 一级节点列：条目名称、条目排序、上架状态、创建时间、修改时间；子条目节点列：子条目排序、上架状态。

（2）新增维度条目

  • 点击"新增维度条目"打开新增弹窗：归属维度、条目名称（最长 20 字符）、条目排序（非负整数）。
  • 新增弹窗不展示上架状态，提交后默认"未上架"。
  • 保存后新条目加入当前维度树。

（3）编辑维度条目

  • 行级"编辑"打开编辑弹窗回填；编辑时可改上架状态。

（4）上架 / 下架 / 批量上架 / 批量下架

  • 维度条目、子条目、子条目项均有行级上/下架，均需弹窗二次确认。
  • 维度条目批量上架/批量下架/批量删除对勾选集合生效，均需二次确认。
  • 上架成功后应用端可获取；下架成功后应用端不可获取。

（5）新增子条目 / 编辑子条目

  • 仅维度条目行展示"新增子条目"，子条目行不展示。
  • 新增/编辑子条目弹窗字段：当前条目名称（只读，显示所属维度条目名称）、子条目名称（文本输入，必填）、子条目排序（数字输入，必填，非负整数）、子条目项（可新增多项，每项含"条目名称"文本输入必填、"排序"数字输入必填）。
  • 子条目项上架状态新增默认"未上架"，保存后在列表中上/下架。

（6）删除 / 批量删除

  • 删除前逐条校验：维度条目处于"已上架"或存在子条目时不可删除，需先下架并删除全部子条目；子条目处于"已上架"或被其他分类引用时不可删除，需先下架或解除引用；子条目项处于"已上架"时不可删除，需先下架。
  • 删除子条目时级联删除其下全部子条目项。
  • 删除均需弹窗二次确认；批量删除逐条判断。

（二）资源管理

资源管理承载资源实体的列表查询、三步式新增/编辑、批量导入、发布/下架、删除与预览；资源通过所属频道、所属分类、类目及类目条目挂接到类目体系。桂教通超管查看全量资源并可直接发布/下架/推荐，后台配置人员仅查看本人创建的资源且按状态限定操作。涉及页面：P10 资源列表页、P11 资源新增/编辑页、P15 资源预览页。

资源列表页

资源列表支持按资源标题、所属频道、所属分类、状态筛选查询，展示资源核心字段，提供预览（打开 P15 资源预览页）、编辑、发布、下架、删除、推荐、批量导入及批量操作；桂教通超管与机构人员在数据范围与操作按钮上存在差异。

（1）查询资源

  • 筛选条件：资源标题（文本输入，模糊）、所属频道（级联选择父频道→子频道）、所属分类（下拉）、状态（下拉，草稿 / 未审批 / 已驳回 / 未发布 / 已发布）。
  • 列表列：资源标题、所属机构、所属频道（子频道名称）、所属分类、排序、查看次数、状态、推荐（推荐时展示"推荐"标签）、更新时间。
  • 按排序升序、排序相同时按修改时间倒序；列表分页展示；无数据时显示"暂无资源数据"。
  • 数据范围：桂教通超管查看全量资源（含所有机构）；后台配置人员仅查看本人创建的资源（R-CFG-04）。

（2）新增资源

  • 点击"新增资源"打开资源新增/编辑页（三步式表单）。
  • 桂教通超管与机构人员均可用，表单结构一致。

（2a）批量导入资源

  • 页面级"批量导入"按钮，桂教通超管与机构人员均可用；弹窗内提供"下载导入模板"、选择 .xlsx 导入文件（单次最多 100 条）。
  • 导入规则（R-RES-13）：
  • 导入仅创建资源基本内容；桂教通超管导入的资源状态为"未发布"，机构人员导入的资源状态为"草稿"（提交审批后走正常审批流）。
  • 内容展示方式=视频/文件·视频的资源导入后，需进入编辑页手动上传对应附件，附件未上传不可发布。
  • 按模板字段校验（资源标题、所属频道、所属分类、内容展示方式、排序、课时、收费方式、资源简介、资源来源机构、资源作者），校验失败的行整行跳过并在结果中提示。

（3）预览资源

  • 行级"预览"仅在状态=已发布（已上架）的资源行展示；点击后打开新界面（P15 资源预览页），按资源内容展示方式呈现（与前台资源查看页正文形态一致）；页头提供"返回列表"回到资源列表。
  • 呈现方式：
  • 富文本：展示富文本详情（资源标题 + 图文正文）。
  • 文件·视频 / 视频：左侧视频播放器（播放/暂停、进度条），右侧附件列表（docx / pdf / mp4 等，按章节分组展示，点击附件切换查看）。
  • 应用和链接 / 链接：以表单详情界面（el-form / el-form-item 形式，label 右对齐）只读展示该资源全部字段（资源标题、所属频道、所属分类、排序、内容展示方式、课时、收费方式、付费方式、价格、应用选择、PC端链接、移动端链接、资源简介、资源来源机构、资源作者、所属机构、状态、更新时间）。
  • 桂教通超管与后台配置人员规则一致（后台配置人员仅限本人创建的已发布资源）。

（4）编辑资源

  • 桂教通超管：仅"草稿"与"未发布"行展示"编辑"，已发布行不展示该按钮，需先下架后编辑。
  • 机构人员：仅"草稿"与"已驳回"行展示"编辑"；"未审批""已发布"行不展示。

（5）发布 / 下架（仅桂教通超管）

  • "发布"在未发布时可用，将资源置为已发布；"下架"在已发布时可用，将资源置为未发布并同步将"是否推荐"置为"否"。
  • 发布、下架均需弹窗二次确认。
  • 机构人员不展示发布/下架按钮。

（6）设为推荐 / 取消推荐（仅桂教通超管）

  • 仅已发布资源可设为推荐；"设为推荐""取消推荐"均需二次确认。
  • 推荐项列表"推荐"列展示"推荐"标签；下架时推荐自动置为"否"。
  • 机构人员不展示推荐按钮。

（7）删除 / 批量删除

  • 桂教通超管：仅"草稿"与"未发布"行展示"删除"；已发布行不展示，需先下架。批量删除逐条判断，已发布项不可删。
  • 机构人员：仅"草稿"与"已驳回"行展示"删除"。
  • 删除均需弹窗二次确认；批量删除对勾选集合逐条判断。

（8）批量发布 / 批量下架 / 批量推荐 / 批量取消推荐（仅桂教通超管）

  • 批量发布：仅将"未发布"项置为"已发布"，已发布项保持不变。
  • 批量下架：仅将"已发布"项置为"未发布"，并同步取消推荐。
  • 批量推荐：仅对所选中的"已发布"项生效，未发布项跳过并在确认文案说明跳过条数。
  • 批量取消推荐：将所选中的"是否推荐=是"项置为"否"，未推荐项保持不变，确认文案说明条数。
  • 五个批量按钮均需二次确认并提示所选条数；未勾选任何行时按钮置灰不可点。

资源新增/编辑页

资源新增/编辑页为三步式表单：基本信息、资源正文、发布设置。桂教通超管可"保存草稿 / 提交 / 提交并发布"，机构人员可"保存草稿 / 提交"（走审批），不展示"提交并发布"按钮。

（1）第一步·基本信息

  • 所属频道：级联选择父频道→子频道，最终存储二级（子频道）的频道ID。
  • 资源标题：必填，最长 30 字符。
  • 资源简介：选填，多行文本，最长 200 字符。
  • 封面：选填，.jpg/.jpeg/.png，尺寸 245×143，≤3MB。
  • 所属分类：单个级联输入框（父频道→子频道→分类），按所属频道（子频道）过滤该子频道下的分类；是否必填取决于该频道下是否存在分类：有分类必填、无分类非必填。
  • 类目及类目条目：展示所属分类所在子频道下所有类目及全部类目条目；其中该分类已关联的类目条目默认勾选且置为只读（不可取消），其余条目可自由勾选/取消；未选所属分类时不展示。
  • 排序：非负整数。
  • 是否在移动端展示：开关控件，默认"是"。

（2）第二步·资源正文

  • 内容展示方式：必填，单选，枚举"富文本 / 文件·视频 / 应用和链接 / 链接 / 视频"（按此顺序排列，视频在最后），决定正文结构。
  • 课时：数字输入，非必填，支持小数点、>0；单位后缀下拉"分钟 / 小时"，默认"分钟"。
  • 收费方式：单选"免费 / 收费"，必填，默认"免费"；内容展示方式=链接时不展示、不采集，按"免费"保存。
  • 收费方式=收费且内容展示方式≠链接：展示"权益"（数字输入，>0、支持小数点，选填）与"权益单位"（后缀下拉"天 / 次"，默认"天"）；留空表示不限制权益。
  • 收费方式=收费且内容展示方式≠应用和链接、≠链接：另展示"应用选择"（可搜索下拉，按名称模糊查询，最多 50 条，必填）作为购买去向；"PC端链接（购买引导）""移动端链接（购买引导）"同条件展示但选填，未填写时应用端不给出购买跳转入口。
  • 内容展示方式=应用和链接：展示"应用"（可搜索下拉，按名称模糊查询，最多 50 条）；"移动端链接""PC端链接"选填；以所选应用自带的收费方式为准，但收费时仍展示权益字段。
  • 内容展示方式=链接：展示"移动端链接""PC端链接"（均必填，≤200 字符）；不采集收费方式、权益与购买引导。
  • 内容展示方式=富文本：展示"内容详情"（富文本，必填），附件通过文件上传器上传（附件标记=附件）。
  • 内容展示方式=文件·视频：展示"是否开启小节"（单选，必填）与文件列表（章节名称、文件上传、排序、删除）；开启小节时章节名称必填。
  • 内容展示方式=视频：展示"是否开启小节"（选填）与文件列表；附件仅支持所有视频格式（.mp4/.avi/.mov/.wmv/.flv/.mkv 等），单个大小 ≤1GB，上传时校验格式与大小，不符合则阻断并提示（R-RES-12）。
  • 文件上传约束：格式 .mp4/.doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf；文档 ≤50MB、视频 ≤500MB；单资源最多 50 个文件。
  • 付费方式、价格不采集，由商城/应用侧维护。

（3）第三步·发布设置

  • 资源来源机构：必填，最长 30 字符。
  • 资源作者：选填，最长 30 字符。

（4）桂教通超管·提交操作

  • "保存草稿"：保存当前表单内容，资源状态置为"草稿"，不执行敏感词过滤。
  • "提交"：先对标题、简介、正文执行机器敏感词过滤；无论是否命中均可保存，状态置为"未发布"；命中时页面顶部提示违规词，需修改通过后方可发布。
  • "提交并发布"：仅当机器敏感词过滤通过时执行，状态置为"已发布"；命中违规词时该动作被拒绝。
  • 三个动作均依赖各步必填字段校验通过。

（5）机构人员·提交操作

  • "保存草稿"：保存当前表单内容，状态置为"草稿"，不执行敏感词过滤。
  • "提交"：先执行机器敏感词过滤，通过后状态置为"未审批"并自动生成一条审批记录；命中违规词时该动作被拒绝（不生成审批记录），需修改后重试或先"保存草稿"。
  • 不展示"提交并发布"按钮。

审批管理集中管理后台配置人员提交的资源审批记录。桂教通超管查看全部审批记录并执行审批，后台配置人员仅查看本人发起的审批记录。涉及页面：P30 审批列表页、P31 审批页。

审批列表页

审批列表支持按机构名称、资源名称、审核状态筛选查询，展示审批记录核心字段；桂教通超管可审批，机构人员仅可查看。

（1）查询审批记录

  • 筛选条件：机构名称（文本输入，模糊）、资源名称（文本输入，模糊）、审核状态（下拉，未审批 / 审批通过 / 已驳回）。
  • 列表列：机构名称、资源名称、所属频道（子频道名称）、所属分类、提交人、审核状态、提交时间。
  • 按提交时间倒序展示；列表分页展示；无数据时显示"暂无审批记录"。
  • 数据范围：桂教通超管查看全量审批记录；后台配置人员仅查看本人发起的审批记录（R-CFG-04）。

（2）审批（仅桂教通超管）

  • 仅审核状态=未审批的行展示"审批"，打开审批页（审批模式）。
  • 机构人员不展示"审批"。

（3）查看

  • 所有状态的行均展示"查看"，打开审批页（查看模式）。
  • 桂教通超管与后台配置人员均可用；后台配置人员仅可查看本人发起的记录。

（4）说明

  • 审批记录由机构人员提交资源时自动生成，本页不提供新增与批量操作。

审批页

审批页上方展示资源详细信息（只读），下方按角色展示审批区域（审批模式）或审批历史（查看模式）。

（1）查看资源详情（只读）

  • 展示字段：资源标题、所属频道、所属分类、类目及类目条目、资源简介、封面、内容展示方式、资源正文内容、资源来源机构、资源作者、所属机构、创建人、排序。

（2）桂教通超管·审批操作（审批模式）

  • 审批通过后，审批记录审核状态置为"审批通过"，审批结果、审批意见、审批人、审批时间落存。

（3）机构人员·查看模式

  • 不展示审批操作区，仅展示资源详情与审批历史（审核状态、审批结果、审批意见、审批人、审批时间）。
  • 点击"关闭/返回"返回审批列表。

（四）硬件与服务管理

硬件与服务管理维护面向应用端的智慧硬件与定制服务（增删改查、发布/下架、批量操作、排序），并集中查看、处理应用端用户提交的预约记录；仅桂教通超管可见。涉及页面：P20 智慧硬件与服务列表页、P21 预约记录列表页、P22 硬件/服务新增/编辑页。

硬件/服务新增/编辑页

  • 名称：必填，最长 30 字符。

  • 字体颜色：必填，默认 #1f2329，十六进制色值 #RRGGBB（兼容 #RGB）。

（六）配置管理

1. 模块描述

配置管理承载"哪些人员可以进入资源后台、进入后可配置哪些频道"的统一配置。仅桂教通超管可见与可操作，包含配置列表页（P40）与配置新增/编辑页（P41）。人员能否进入后台、可配置哪些频道，均由配置记录决定；人员停用或删除后立即失去后台访问能力。

登录权限判定（R-CFG-04）：人员登录后，系统按后台人员配置列表判断登录人是否有权限；配置内人员的菜单权限=资源列表+审批列表，数据范围=仅本人创建的资源与本人发起的审批数据；未配置人员不可进入资源后台。

2. P40 配置列表页

功能描述：后台访问人员的列表查询与管理入口。

  • 筛选条件：姓名或手机号（模糊）、所属机构（模糊）、状态（启用/停用）。
  • 列表展示：姓名、手机号、部门、所属机构、可配置频道（展示频道名称集合，超过 3 个折叠为"前 3 个 + 等 N 个"）、状态、更新时间。
  • 行级操作：
  • 编辑：打开 P41 编辑模式，回填当前值。
  • 启用/停用：二次确认；停用后该人员立即失去后台访问能力，启用后恢复。
  • 删除：二次确认；删除后该人员立即失去后台访问能力。
  • 页面级操作：新增配置（打开 P41 新增模式）。

3. P41 配置新增/编辑页

功能描述：新增或修改后台访问人员配置（弹窗/抽屉）。人员来源于身份系统的机构人员库，不采集登录账号、角色类型与状态。

  • 表单字段与校验：
  • 所属机构：第一行，必填，可搜索下拉；选中后限定"姓名"的可选人员范围。
  • 姓名：必填，可搜索下拉，按所属机构过滤人员；选项展示"姓名/手机尾号4位(部门)"并带姓氏头像圆标；切换机构后清空已选人员。
  • 手机号：必填，只读；选择人员后自动带出，不可编辑。
  • 可配置频道：必填，按频道父子层级多选，至少勾选 1 个（R-CFG-05）。
  • 状态：不落表单，新增提交后状态固定为"启用"（R-CFG-03）。
  • 页面级操作：保存（校验通过后保存并返回列表；同一人员（所属机构+手机号）不可重复配置，重复则阻断并提示"该人员已在配置列表"）、取消（放弃修改返回列表）。

4. 规则

  • R-CFG-01 同一人员（所属机构 + 手机号）仅可配置一条：保存时校验，重复则阻断保存并提示"该人员已在配置列表"。
  • R-CFG-02 姓名与手机号由人员选择带出：先选所属机构（第一行，可搜索下拉），再在该机构人员中搜索选择姓名（选项展示"姓名/手机尾号4位(部门)"并带姓氏头像），选中后自动带出手机号（必填、只读）与部门；切换机构后清空已选人员。
  • R-CFG-03 状态不落表单：新增提交后状态固定为"启用"；列表内可启用/停用，停用后人员立即失去资源后台访问能力，启用后恢复。
  • R-CFG-04 登录权限判定：人员登录后系统按后台人员配置判断是否有权限进入资源后台；配置内人员菜单权限=资源列表+审批列表，数据范围=仅本人创建的资源与审批数据；未配置人员不可进入后台。
  • R-CFG-05 可配置频道至少勾选 1 个，决定该人员在频道相关页面（频道管理、分类管理、条目管理、资源按频道筛选等）可见与可操作的数据范围。
  • R-CFG-06 删除仅做二次确认，删除后该人员立即失去后台访问能力；人员相关操作留痕保留。

七 状态机

7.1 分类状态机

  • 状态集合：未上架、已上架。
  • 迁移：
  • 未上架 → 已上架：管理员触发"上架"动作 + 二次确认；系统写入上架状态并通知应用端。
  • 已上架 → 未上架：管理员触发"下架"动作 + 二次确认；系统写入未上架状态并通知应用端。
  • 限制：已上架状态下禁止删除。

7.2 维度条目状态机

  • 状态集合：未上架、已上架。
  • 迁移规则同分类状态机。
  • 限制：已上架状态下禁止删除。

7.3 分类维度上架状态机

  • 状态集合：上架、下架。
  • 初始：新增分类维度提交后默认进入下架（新增弹窗不展示上架状态字段）。
  • 迁移：
  • 上架 → 下架：管理员触发"下架"动作；应用端不再渲染该维度，但配置保留。
  • 下架 → 上架：管理员触发"上架"动作；应用端恢复渲染该维度。
  • 限制：维度下存在维度条目时禁止删除。

7.4 资源状态机

  • 状态集合：草稿、未审批、已驳回、未发布、已发布。
  • 初始：新增资源"保存草稿"进入草稿。

7.4.1 桂教通超管路径

  • 迁移：
  • 草稿 → 未发布：超管触发"提交"动作（不受敏感词过滤限制，但违规资源不可继续发布）。
  • 草稿 → 已发布：超管触发"提交并发布"动作；须机器敏感词过滤通过，命中时拒绝。
  • 未发布 → 已发布：超管触发列表"发布"或"批量发布"；前置约束：机器审核结果必须为"通过"。
  • 已发布 → 未发布：超管触发"下架"或"批量下架" + 二次确认；同步将"是否推荐"置为"否"。
  • 限制：已发布状态下禁止删除和编辑；草稿与未发布状态下可编辑和删除。

7.4.2 机构人员路径

  • 迁移：
  • 草稿 → 未审批：机构人员触发"提交"；须机器敏感词过滤通过，通过后自动生成审批记录。
  • 未审批 → 已发布：超管审批通过后系统自动迁移；应用端可获取。
  • 未审批 → 已驳回：超管审批驳回后系统自动迁移。
  • 已驳回 → 未审批：机构人员修改后重新"提交"；须再次通过机器敏感词过滤；复用原审批记录。
  • 已发布 → 未发布：仅超管可下架（机构人员不可操作）+ 二次确认。
  • 未发布 → 已发布：仅超管可重新发布（机构人员不可操作）。
  • 限制：未审批状态下禁止编辑和删除；已发布状态下机构人员仅可预览；草稿与已驳回状态下可编辑和删除。
  • 推荐：是否推荐仅在已发布状态下可由超管置为"是"（单条或批量，均需二次确认）；下架后自动回到"否"。

7.5 审批记录状态机

  • 状态集合：未审批、审批通过、已驳回。
  • 初始：机构人员提交资源时自动生成，进入未审批。
  • 迁移：
  • 未审批 → 审批通过：桂教通超管在审批页选择"通过"并提交；系统同步将关联资源状态置为已发布。
  • 未审批 → 已驳回：桂教通超管在审批页选择"驳回"并提交；系统同步将关联资源状态置为已驳回。
  • 已驳回 → 未审批：机构人员修改已驳回的资源后重新提交；复用同一条审批记录，清空原审批结果、审批意见、审批人、审批时间，审核状态重置为未审批。
  • 限制：审批记录不可删除；仅桂教通超管可执行审批操作。

7.6 智慧硬件与服务状态机

  • 状态集合：未发布、已发布、已下架。
  • 初始：新增保存后进入未发布。
  • 迁移：
  • 未发布 → 已发布：管理员触发"发布"或"批量发布" + 二次确认；应用端可获取并可预约。
  • 已下架 → 已发布：管理员触发"发布"或"批量发布" + 二次确认。
  • 已发布 → 已下架：管理员触发"下架"或"批量下架" + 二次确认；应用端不再展示，已产生的预约记录保留。
  • 限制：已发布状态下禁止删除；编辑保存不改变状态。

7.7 预约记录状态机

  • 状态集合：待处理、已受理、已完成、已取消。
  • 初始：应用端提交后进入待处理。
  • 迁移：
  • 待处理 → 已受理：管理员触发"受理"动作 + 二次确认。
  • 待处理 / 已受理 → 已取消：管理员触发"取消"动作 + 二次确认。
  • 已受理 → 已完成：线下服务完成后由系统或管理员标记。
  • 限制：预约记录不可删除。

7.8 频道

  • 无上下架状态机；仅有"是否在资源中心展示"开关字段（是 / 否），由管理员在新增/编辑时直接维护。

7.9 后台人员配置（账号）状态机

  • 状态集合：启用、停用。
  • 迁移：
  • 启用 → 停用：超管触发"停用"动作 + 二次确认；该人员立即失去资源后台访问能力。
  • 停用 → 启用：超管触发"启用"动作；访问能力恢复。
  • 限制：内置超级管理员账号不可停用、不可删除；删除动作不区分状态，删除后立即失去访问能力。
