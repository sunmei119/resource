1. 先搞清楚：怎么一步步搭起来

系统是个层层套娃：父频道 → 子频道 → 分类 → 维度配置 → 资源。建议按这个顺序来：

  1. 先建频道：父频道建好，再在下面挂子频道（最多两层，子频道不能再挂子级）。
  2. 再建分类：在子频道下建一级/子分类（最多两层）。一级分类要关联"类目条目"。
  3. 配维度：去"条目管理"里，先建分类维度（比如"学段"），再给每个维度建条目（比如"小学""初中"）、子条目、子条目项。
  4. 上架下发：频道、分类、维度条目都配好后，分别点"上架"，手机端 App 才能看到。
  5. 挂资源：最后到"资源管理"里加资源，选好频道/分类，提交或提交并发布。
  6. 上硬件/服务：到"硬件与服务管理 → 智慧硬件与服务"里点"新增"，会打开一个独立的新增页，填好（名称、类型、频道/分类、排序、背景色、字体颜色、简介、详细介绍、详细介绍图片、附件）保存后点"发布"；已发布的项，用户在 App 提交的预约会进"预约记录"，你去那里受理或取消。
小知识：App 已经在用这批数据了。你上架了 App 才看得到，下架了就看不到；下架/删除不改变 App 原来的页面样子。

2. 这些操作到处都一样

操作怎么用
查询改完筛选条件点"查询"（回到第 1 页）；"重置"一键清空
新增 / 编辑右上角或每行末尾的按钮开弹窗；填错会即时飘红，点"保存/提交"再整体校验一遍
上架 / 下架行尾按钮，点完二次确认，状态同步到 App
删除行尾"删除"（单个）或勾选后"批量删除"，都要二次确认
级联选择（所属频道 / 所属分类）先选爸爸再选儿子；没选到第二级（子频道/子分类）之前不让提交
保存中途关弹窗会问你"当前修改尚未保存，确认关闭？"，确定就丢掉，取消就留着
记住一条：上架 / 下架 / 删除（单条或批量）都会弹二次确认，别慌，看清楚再点确定。

3. 频道管理

入口 类目管理 → 频道管理

3.1 查频道

  • 按"频道名称（模糊）""是否在资源中心展示"筛选。
  • 列表是树形：父频道在上，子频道缩进挂在下面。
  • 排序先按"排序"升序，同排序再按"修改时间"倒序。
  • 没数据会提示"暂无频道，请点击右上角新增"。
📷 截图占位频道管理列表页（树形 + 筛选栏）

3.2 新增父频道

点右上角"新增父频道"：

字段必填规则
频道名称是最多 20 字
频道图标是68×68，≤100KB
频道图片是≤300KB
是否在资源中心展示是默认"否"
排序是非负整数
频道描述否最多 200 字
保存成功会自动跳到新那条；保存失败会保留你填的内容并顶部报错。
📷 截图占位新增父频道弹窗（带必填标记）

3.3 添加子频道

父频道行尾点"添加子频道"：父频道信息自动带上且只读，其余规则同父频道（频道图片除外：新增子频道时频道图片选填，大小限制在 5M 内，不传也行）。子频道不能再挂子级。

3.4 编辑频道

行尾点"编辑"：所有字段都能改；图标/图片可替换；子频道的"父频道"是只读的。

3.5 删除频道

  • 单个删：行尾"删除" → 二次确认"确认删除频道？"
    • 被分类引用了不能删，会提示"频道 X 已被分类引用，不可删除"。
    • 父频道下还有子频道也不能删，得先删光子频道，提示"父频道 X 下存在子频道，请先删除全部子频道"。
  • 批量删：勾选后点"批量删除"，引用中或有子频道的会被跳过，最后告诉你哪些没删成。
📷 截图占位删除频道二次确认弹窗 + 引用拦截提示

4. 分类管理

入口 类目管理 → 分类管理

4.1 查分类

  • 按"所属频道（父→子）""分类名称（模糊）""上架状态"筛选。
  • 列表可展开/收起，符合条件的节点会自动展开。
📷 截图占位分类管理列表（树形 + 状态标签）

4.2 新增一级分类

点右上角"新增一级分类"：

  1. 先选"所属频道"（级联到子频道，必选）。
  2. 如果这子频道下有已上架的类目条目，就会出现"类目及类目条目"一栏（必填，至少勾一个）：
    • 按类目一行行列出条目，逐个勾。
    • 关键点：勾了某个条目后，如果它下面有"已上架"的子条目，会自动把对应子条目展开让你继续勾（只显示已上架的；没勾的条目不会显示它的子条目）。
  3. 如果这子频道下压根没有类目条目，那"类目及类目条目"整栏都不出现。
字段必填规则
所属频道是必须选到子频道
分类名称是最多 20 字
分类编码是最多 10 字，不能填中文
排序是非负整数
分类图标否图片上传，1 张；.jpg/.jpeg/.png；≤2MB；传错了可以"移除"重传；不传也能保存，App 端就不显示图标
分类封面否图片上传，1 张；.jpg/.jpeg/.png；≤5MB；传错了可以"移除"重传；不传也能保存，App 端用默认封面
按钮文字否最多 10 字，App 端分类入口按钮上显示的文案；留空则不展示按钮
类目及类目条目看情况有已上架类目条目时必填
分类描述否最多 200 字
📷 截图占位新增一级分类弹窗——勾选条目后展开子条目勾选区

4.3 添加子分类

某分类行尾点"添加子分类"：父分类、所属频道自动继承且只读，不出现类目条目那栏（子分类只挂父分类）；分类图标、分类封面、按钮文字同样可以填，都是选填。

4.4 编辑分类

行尾点"编辑"：

  • 所属频道 / 父分类能改；改所属频道会弹"将同时移动其子分类，是否继续？"
  • 一级分类会把已勾的条目和子条目都回填进来；子分类没这栏。
  • 分类图标、分类封面、按钮文字都会回填，可直接替换或"移除"重传。
  • 编码撞车会在表单顶部提示并保留你填的内容。

4.5 上架 / 下架分类

  • 上架：二次确认"确认上架分类？" → 状态变"已上架"，App 能看到。
  • 下架：二次确认"确认下架分类？" → 变"未上架"，App 看不到了（它下面已上架的条目各自保留状态，只是不再跟着分类下发）。

4.6 删除分类

  • 单个删：行尾"删除" → 二次确认"确认删除分类？删除后不可恢复。已上架分类不允许删除。"
    • 已上架时删除按钮是灰的，悬停会提示"请先下架再删除"。
  • 批量删：已上架的会被跳过，最后列出没删成的。
  • 删一级分类会顺带把它下面所有子分类一起删（确认框里会额外提醒）。
📷 截图占位分类上架状态标签 + 删除置灰态

5. 条目管理

入口 类目管理 → 条目管理，有两个 Tab：

  • 分类管理 Tab：维护分类维度（比如"学段/年级/学科"）
  • 分类条目管理 Tab：维护维度下的维度条目、子条目、子条目项
📷 截图占位条目管理两个 Tab 切换 + 归属维度选择器

5.1 分类管理 Tab（分类维度）

操作说明
查询按所属频道、维度名称（模糊）、上架状态筛
新增分类维度点"新增分类维度"，填所属频道、维度名称（≤20）、排序（非负整数）；新增不显示上架状态，提交默认"下架"
编辑行尾"编辑"，都能改
批量上架/下架/删除勾选后点顶部按钮；有维度条目的维度删不掉，会列出
删除维度单个删二次确认"确认删除分类维度？…维度下存在维度条目时不允许删除，请先清空关联数据"；有条目时按钮灰

5.2 分类条目管理 Tab（维度条目）

前提：顶部必须先选"归属维度"整表才出来；没选会提示"请先选择归属维度"。

5.2.1 新增维度条目

点"新增维度条目"：归属维度默认带当前值但可改；不显示上架状态，提交默认"未上架"。

字段必填规则
归属维度是只显示已上架的维度
条目名称是最多 20 字
条目排序是非负整数
上架状态仅编辑有新增默认未上架

5.2.2 新增子条目

维度条目行尾点"新增子条目"：

  1. "当前条目名称"自动带上，只读。
  2. 填子条目名称（必填，≤20）、子条目排序（必填，非负整数）。
  3. 点"新增子条目项"加若干子条目项，每项填：
    • 条目名称（必填，≤20）
    • 排序（必填，非负整数）
    • 上架状态（默认"未上架"，保存后能在列表上下架）
  4. 保存后该维度条目自动展开，子条目是第二层，子条目项挂在子条目下面。
只有两层：子条目那一行没有"新增子条目"按钮（子条目下面不能再建子条目）。
📷 截图占位新增子条目弹窗（含子条目项列表 + 上架状态）

5.2.3 上架 / 下架

  • 维度条目和子条目：行尾"上架/下架"，二次确认；只有"已上架"的才在 App 渲染。
  • 子条目项：行内"上架/下架"，二次确认；只有"已上架"的子条目项才在 App 渲染。

5.2.4 删除（注意会连坐）

删谁二次确认文案删不掉的情况
维度条目"确认删除条目？删除后不可恢复。若条目下存在子条目，则条目无法删除"已上架 / 下面还有子条目（先下架 / 先删子条目）
子条目"确认删除子条目？删除后该子条目及其下所有子条目项将一并移除，且不可恢复。被其他分类引用的子条目不可删除。"已上架 / 被别的分类引用（先下架 / 先解除引用）；确认后会把下面所有子条目项一起删
子条目项"确认删除该子条目项？删除后不可恢复"已上架（先下架）
删失败的话列表不会变。
📷 截图占位子条目删除二次确认弹窗（含级联/引用提示）

6. 资源管理

入口 资源管理 → 资源管理

6.1 查资源

按"资源标题（模糊）""所属频道（级联）""所属分类""状态（草稿 / 未审批 / 已驳回 / 未发布 / 已发布）"筛选。

数据范围：桂教通超管看到的是全量资源，包括各机构人员创建的草稿、未审批、已驳回这些还没过审的数据，方便掌握全平台内容；机构人员只看得到自己创建的资源（列表标题旁有一行小字注明当前数据范围）。
📷 截图占位资源管理列表（状态标签 + 行级操作）

6.2 资源列表行级操作

操作说明
预览打开一个模拟 App 详情页
编辑超管的"草稿 / 未发布"行、机构人员的"草稿 / 已驳回 / 未发布"行才有这个按钮，进编辑页三步表单自动回填；"已发布"行不显示，要先"下架"
上架 / 发布只有"未发布"能点（仅超管）；二次确认后变"已发布"（App 可获取）
下架只有"已发布"能点，超管和机构人员都行（机构只能下架自己创建的资源）；二次确认后变"未发布"，同时取消推荐。机构下架就是为了调整已审核资源的内容——下架完点"编辑"改完再"提交"，会重新生成审批，回到"未审批"等超管再批
设为推荐 / 取消推荐只有"已发布"行才有这个按钮（仅超管）；未推荐时显示"设为推荐"，已推荐时显示"取消推荐"，都要二次确认；推荐的资源在列表"推荐"列有红色标签，App 推荐位展示
删除超管的"草稿 / 已驳回 / 未发布"行、机构人员的"草稿 / 已驳回"行才有这个按钮，二次确认删；"已发布"行不显示，要先"下架"

6.3 批量操作（勾选左侧复选框，表头可全选）

按钮说明
批量上架把勾选里的"未发布"都置为"已发布"；已经是"已发布"的保持不变
批量下架把勾选里的"已发布"都置为"未发布"，并同步取消推荐
批量推荐只把勾选里的"已发布"设为推荐；"未发布"的不支持推荐会被跳过，确认框里会告诉你跳过几条
批量取消推荐把勾选里"是否推荐=是"的都改成"否"，本来就没推荐的不动；不受上架状态限制
批量删除已发布的会被跳过，最后列出没删的
一个都没勾时，这四个按钮都是灰的；批量操作只有超管能看，机构人员没有这部分按钮。

6.4 机构资源的审批流程（要改"已发布"资源的看这里）

  1. 机构人员新建资源，可以先"保存草稿"；内容填完点"提交"，资源变"未审批"，系统自动生成一条审批记录。
  2. 桂教通超管去"审批管理"审批：通过 → 资源自动变"已发布"，App 能获取；驳回 → 资源变"已驳回"（机构人员改完内容再"提交"，重新生成审批，回到"未审批"）。
  3. 已发布的资源要改内容：机构人员先对这条资源点"下架"（变"未发布"），再点"编辑"调整内容，最后"提交"——重新生成一条审批记录，资源回到"未审批"，超管再批一次：通过就重新"已发布"，驳回就继续"已驳回"（还能再改再提交）。
  4. "审批管理"列表右上角有"查看审批流程"，点开就是上面这条完整流程图，忘了随时看。

6.5 新增 / 编辑资源（三步走）

步骤条：基本信息 → 资源正文 → 发布设置，每步"下一步"会校验这步的必填项。

字段必填规则
所属频道是父→子，存子频道ID
资源标题是最多 30 字
资源简介否最多 200 字
封面否.jpg/.jpeg/.png，245×143，≤3MB
所属分类是按子频道过滤出一级分类
排序是非负整数
是否在移动端展示是开关，默认"是"
📷 截图占位资源新增-第一步基本信息

第二步 · 资源正文

  • 内容展示方式（必填）：富文本 / 文件·视频 / 应用和链接 / 链接，切换时表单整体变。
  • 收费方式（必填）：免费 / 收费，默认"免费"；内容展示方式选了"链接"时不显示这一项。
  • 权益（收费时出现，选填）：只要收费方式选了"收费"就会出现（选"应用和链接"也会出现），内容展示方式="链接"时不显示。要填就先填数量（数字，支持小数，如 7、3），再在右边的下拉里选单位：天 / 次（默认"天"），例如"7 天""3 次"——天表示权益有效时长，次表示权益可用次数；不填也能保存，表示不限制权益。填了数量但不是大于 0 的数字（比如填 0 或填文字）才会被拦住。
  • 购买引导（应用选择 / PC端链接 / 移动端链接）：只有"收费方式=收费"且"内容展示方式不是应用和链接、也不是链接"时才出现；出现后只有应用选择必填（搜索下拉），PC端链接 / 移动端链接改成选填（最长 200 字），不填也能保存，只是不会给 App 用户的购买跳转入口，用户去商城购买页 fallback。
    • 内容展示方式就是"应用和链接"时不重复出现，系统按你选的那个应用是否收费自动判定。
    • 付费方式、价格仍然不在后台录，由商城/应用侧维护。
  • 按展示方式填内容：
    • 富文本：内容详情（必填）、附件（选填）。
    • 文件·视频：是否开启小节（默认"否"，必填）；加文件（.mp4/.doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf，最多 50 个，文档≤50MB、视频≤500MB）。
    • 应用和链接：应用（必填）+ 移动端/PC端链接（选填）。
    • 链接：移动端链接、PC端链接（都必填，≤200 字）；链接方式下不显示收费方式、权益和购买引导，系统按免费资源保存。

提交

  • 提交：先跑一遍机器敏感词过滤（标题/简介/正文）；中不命中都存成"未发布"；命中了会在顶部提示你得改完才能发布。
  • 提交并发布：也先过滤；只有过滤通过才让发布（变"已发布"），命中就拒绝并列出违规词，你可以先"提交"存成未发布。

7. 硬件与服务管理

入口 硬件与服务管理 → 智慧硬件与服务 / 预约记录

7.1 查硬件/服务

按"名称（模糊）""频道（级联父→子）""分类（按频道过滤）""状态（全部/未发布/已发布/已下架）"筛选。

📷 截图占位智慧硬件与服务列表（类型标签 + 状态标签 + 行级操作）

7.2 列表行级操作

操作说明
编辑打开"新增/编辑页"并回填当前值，保存即生效；编辑不改变状态
发布"未发布""已下架"能点；二次确认后变"已发布"，App 可见且用户可预约
下架只有"已发布"能点；二次确认后变"已下架"，App 不再展示（已有预约记录保留）
删除"已发布"是灰的不能删（先下架）；"未发布""已下架"二次确认删

7.3 批量发布 / 批量下架

勾选左侧复选框（表头可全选当前页）后点"批量发布"或"批量下架"，二次确认并提示所选条数；已是"已发布"的项在批量发布时保持不变。一个都没勾时，两个按钮是灰的。

7.4 新增 / 编辑硬件或服务（独立页面）

点列表右上角"新增"，或行末"编辑"，会打开一个新页面（不是弹窗）：新增时标题是"新增硬件/服务"，编辑时是"编辑硬件/服务"并回填当前值。

字段必填规则
名称是最长 30 字符
类型是智慧硬件 / 定制服务，默认"智慧硬件"
所属频道是父→子，必须选到子频道；换频道会清空已选分类
所属分类条件必填按所属频道过滤；该频道下有分类就必填，没有就不填
排序是非负整数，越小越靠前
背景色是文本输入，十六进制色值，如 #ffffff（也认 #fff）；输对了右边有色块预览
字体颜色是同上，如 #1f2329
简介是最长 50 字符
详细介绍是最长 200 字符
详细介绍图片是图片上传，支持一次传多张；.jpg/.jpeg/.png；单张 ≤10MB；传错了可以"移除"
附件上传否最多 5 个；单个 ≤20MB；.doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf

页面底部"保存" / "取消"，右上角还有"返回列表"：

  • 保存：逐项校验，哪一项没填或格式不对会直接告诉你原因（例如"背景色格式不正确，请输入 #ffffff 形式的十六进制色值"）；通过后自动回到列表页
  • 取消 / 返回列表：放弃这次修改回到列表页
  • 新增保存后状态是"未发布"，记得回列表点"发布"
  • 编辑"已发布"的项再保存，状态不变，不用重新发布

7.5 预约记录

操作说明
查按"名称（模糊）""预约人（模糊）""状态（全部/待处理/已受理/已完成/已取消）"筛选
看详情点"查看"弹窗，看预约人、联系方式、预约时间、预约说明等
受理只有"待处理"能点；二次确认后变"已受理"，记得线下联系预约人
取消"待处理""已受理"能点；二次确认后变"已取消"
预约是用户在 App 提交的，后台不能新增也不能删，只能查看、受理、取消。

8. 哪些不能删？一张表看明白

对象删不掉的情况连带影响
频道被分类引用了；下面还有子频道先删子频道 / 先解除分类引用
分类已上架先下架；删一级分类会连子分类一起删
分类维度下面还有维度条目先清空维度条目
维度条目已上架；下面还有子条目先下架 / 先删子条目
子条目已上架；被别的分类引用先下架 / 先解除引用；删时连子条目项一起删
子条目项已上架先下架
资源已发布先下架
硬件/服务已发布先下架
预约记录一律不能删只能查看、受理、取消
上架同步规则：频道、分类、维度条目、子条目、子条目项的上架状态都同步到 App 可见性；只有"已上架"的维度条目及其子条目、子条目项才在 App 渲染。

9. 踩坑了看这里

现象为啥 / 咋办
分类删除按钮是灰的分类"已上架"，先"下架"再删
子条目删除按钮是灰的子条目已上架（先下架），或被别的分类引用了（先解除引用）
新增一级分类看不到"类目条目"栏这子频道下还没有已上架类目条目；或者你还没选到子频道
勾了条目却没看到子条目这条目下没有"已上架"的子条目；没勾的条目不会显示它的子条目
维度条目删不掉已上架，或下面还有子条目；先下架并删光子条目
父频道删不掉还被分类引用，或下面还有子频道；先处理
资源发布被拒标题/简介/正文踩了敏感词；可以先"提交"存未发布，改完再发
批量操作有些没生效已上架 / 被引用 / 有子级的会被跳过，结果会告诉你哪些没处理
"批量上架 / 批量下架 / 批量推荐"按钮是灰的还没勾选任何行；先勾左侧复选框
找不到"设为推荐"按钮只有"已发布"的资源才有，先"上架"再设
批量推荐有几条没设上未上架的资源不支持推荐，会被跳过，确认框里会写跳过几条
资源下架后推荐没了正常：下架会同时取消推荐，重新上架后要再设一次
硬件/服务删不掉或按钮是灰的状态是"已发布"，先"下架"再删
预约记录想新增或删除不支持，预约只能由 App 端提交，后台只能查看、受理、取消
敏感词范围：涉政、色情低俗、暴恐、赌博、诈骗广告、辱骂、隐私泄露、虚假医疗、未成年人保护等。所有文字输入落库和发布前都会过一遍。
