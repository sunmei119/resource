# 设计基线

## 一、文档概述

本设计基线对应 [对齐稿](file:///d:/claudeCode/AIProject/ShitPM2/output/align/align.md)，覆盖"资源中心管理后台"一期建设的类目管理、资源管理、审批管理与硬件服务管理能力。设计目标：

- 明确桂教通超管与机构人员两种角色在各模块下的操作意图、页面结构与权限边界
- 定义频道（支持父/子两级层级）、分类两类基础实体，分类维度、维度条目两类维度配置实体，资源、资源文件两类资源实体，审批记录实体，以及智慧硬件与服务、预约记录两类硬件与服务实体的字段、状态与业务规则
- 明确上架/下架、发布/下架与应用端可见性的契约点
- 明确资源审批流程：机构人员提交资源需桂教通超管审批，审批通过后自动发布

本设计不包含登录与对外接口契约（对外接口由后端团队独立设计，仅需在本文档中约定契约点）。权限按桂教通超管与机构人员两种角色定义，详见第十章。

## 二、范围与建设方式

- 建设方式：`new_build`（全新建设后台侧，数据侧需兼容已有应用端消费的类目数据）
- 一期范围：类目管理 → 频道管理 / 分类管理 / 条目管理（仅桂教通超管可见）；资源管理 → 资源列表（全角色可见，机构人员仅限本机构数据）；审批管理 → 审批列表（全角色可见，机构人员仅限本机构数据）；硬件与服务管理 → 智慧硬件与服务 / 预约记录（仅桂教通超管可见）
- 导航结构：
  - 类目管理（仅桂教通超管可见）
    - 频道管理
    - 分类管理
    - 条目管理
  - 资源管理
    - 资源列表
  - 审批管理
    - 审批列表
  - 硬件与服务管理（仅桂教通超管可见）
    - 智慧硬件与服务
    - 预约记录
- 明确不做：登录、对外接口契约

## 三、角色定义

| 角色 | 职责 | 数据可见范围 | 权限层级 |
|---|---|---|---|
| 桂教通超管 | 维护频道、分类的增删改查与上下架，维护分类维度、维度条目配置，维护资源的增删改查、直接发布/下架与预览，审批其他机构提交的资源，维护智慧硬件与服务的增删改查与发布/下架，查看并处理预约记录，维护后台人员配置（控制哪些人员可进入资源后台及其可配置频道） | 全量类目、全量资源（含所有机构，含机构人员创建的草稿/未审批/已驳回等全部状态）、全量审批记录、全量硬件与服务及预约数据、全量后台人员配置 | 全功能角色，可见所有导航模块 |
| 机构人员 | 新增/编辑/提交本人创建的资源（需超管审批后方可发布），管理本人创建的草稿与被驳回资源，查看本人发起的审批记录 | 仅本人创建的资源数据、仅本人发起的审批记录 | 受限角色：仅可见"资源管理"与"审批管理"两个导航模块（即后台人员配置的菜单权限，R-CFG-04）；不可见"类目管理"与"硬件与服务管理" |

说明：
- 桂教通超管新增资源时无需审批，可直接发布
- 机构人员新增资源提交后自动生成审批记录（同一资源仅一条，重新提交复用），超管审批通过后资源自动发布
- 机构归属由登录身份系统确定，本设计不包含登录模块实现，仅约定"所属机构"字段由身份系统写入
- 后台访问人员由"配置管理"模块维护：人员能否进入资源后台、可配置哪些频道，均由配置记录决定；配置内人员菜单权限=资源列表+审批列表，数据范围=本人创建的资源与审批数据；人员停用/删除后立即失去后台访问能力
- 资源中心门户（前台展示端）不受角色区分影响，仅展示已发布资源

## 四、模块定义

### 类目管理（顶层模块，仅桂教通超管可见）

- 职责：统一维护类目体系，为已有应用端提供上架后的稳定类目数据
- 包含子模块：频道管理、分类管理、条目管理
- 数据关系：频道 1—N 分类；分类维度 1—N 维度条目

#### 频道管理子模块

- 职责：频道的增删改查、是否展示开关、同层级排序；支持父频道下新增/编辑子频道，层级最多两级（一级=父频道，二级=子频道）
- 包含页面：频道列表页、频道新增/编辑页

#### 分类管理子模块

- 职责：分类与子分类的增删改查、上下架、同层级排序；分类挂靠到二级频道（子频道）；一级（顶级）分类可选择关联该子频道下的类目及类目条目，二级（子）分类无需关联类目条目
- 包含页面：分类列表页、分类新增/编辑页

#### 条目管理子模块

- 职责：通过"分类维度—维度条目—子条目"结构，替代硬编码的"学段/年级/学科"结构，支持后台可视化新增、修改、删除分类维度及维度下的维度条目；维度条目以树形展示（最多两层：维度条目 → 子条目），可下挂子条目（子条目含"子条目排序"字段，必填、非负整数，用于子条目之间的展示顺序），子条目以"子条目项（条目名称 + 排序 + 上架状态）"呈现叶子内容，子条目项支持上/下架与删除（已上架不可删），子条目下不可再新增子条目；被其他分类引用的子条目不可删除；分类维度直接挂靠到子频道（不再挂靠到分类），前端筛选视图按后台配置动态渲染
- 包含页面：条目管理两 Tab 页（P07/P08，分别承载分类管理、分类条目管理）

### 资源管理（顶层模块，全角色可见）

- 职责：管理资源中心的资源实体，支持资源的列表查询、分步新增/编辑、批量导入、发布/下架、删除与预览；资源通过所属频道、所属分类、类目及类目条目挂接到类目体系；桂教通超管可直接发布/下架资源，后台配置人员新增资源需提交审批
- 包含子模块：资源列表
- 数据关系：资源 N—1 频道；资源 N—1 分类；资源 N—M 维度条目（类目及类目条目多选）；资源 1—N 资源文件；资源 N—1 机构
- 角色差异：
  - 桂教通超管：查看全量资源（含机构人员的草稿/未审批/已驳回等全部状态），可新增/编辑/批量导入/发布/下架/删除/预览/推荐，操作同原有流程
  - 后台配置人员（机构人员）：仅查看本人创建的资源，可新增/编辑（草稿、已驳回与未发布状态，已驳回即"重新编辑"）/批量导入/提交/删除（草稿与已驳回状态）/撤回审核（仅本人"未审批"资源）/预览/下架（仅本人已发布资源，用于调整内容后重新提交审批，提交复用该资源的审批记录，同一资源仅一条）；不可直接发布/推荐

#### 资源列表子模块

- 职责：资源的列表查询与筛选、三步式新增/编辑（基本信息 / 资源正文 / 发布设置）、批量导入、发布/下架、删除、预览
- 包含页面：资源列表页、资源新增/编辑页、资源预览页

### 审批管理（顶层模块，全角色可见）

- 职责：集中管理后台配置人员提交的资源审批记录（同一资源仅一条，历次审批明细累计为审批历史）；桂教通超管可查看全部审批记录并执行审批操作，后台配置人员仅可查看本人发起的审批记录
- 包含子模块：审批列表
- 数据关系：审批记录 N—1 资源

#### 审批列表子模块

- 职责：审批记录的列表查询与筛选、审批操作（通过/驳回）、查看资源详情与审批信息
- 包含页面：审批列表页、审批页/查看页

### 配置管理（顶层模块，仅桂教通超管可见）

- 职责：配置哪些人员可以进入资源后台，并为每位人员分配可配置的频道范围；人员停用/删除后立即失去后台访问能力
- 包含子模块：后台人员配置
- 数据关系：后台人员配置 N—1 机构；后台人员配置 N—M 频道（可配置频道多选）

#### 后台人员配置子模块

- 职责：后台访问人员的增删改查、启用/停用；人员来源于身份系统的机构人员库：新增时先选所属机构（可搜索下拉），再在该机构人员中搜索选择姓名（选项展示"姓名/手机尾号4位(部门)"并带姓氏头像），选中后自动带出手机号（必填、只读）与部门；配置可配置频道（至少 1 个）；新增提交后状态固定为"启用"
- 登录权限判定：人员登录后系统按后台人员配置判断是否有权限进入资源后台；配置内人员菜单权限=资源列表+审批列表，数据范围=仅本人创建的资源与审批数据（R-CFG-04）
- 包含页面：配置列表页、配置新增/编辑页

### 硬件与服务管理（顶层模块，仅桂教通超管可见）

- 职责：统一维护面向应用端的智慧硬件与定制服务，承载其发布/下架与查询统计；并集中查看、处理应用端用户提交的预约记录
- 包含子模块：智慧硬件与服务、预约记录
- 数据关系：硬件/服务 N—1 频道（子频道）；硬件/服务 N—1 分类；硬件/服务 1—N 预约记录

#### 智慧硬件与服务子模块

- 职责：智慧硬件与定制服务的增删改查、发布/下架、批量发布/批量下架、排序；通过所属频道、所属分类挂接到类目体系，并维护应用端展示所需的背景色、字体颜色、简介、详细介绍与详细介绍图片、附件
- 包含页面：智慧硬件与服务列表页、硬件/服务新增/编辑页

#### 预约记录子模块

- 职责：汇总应用端用户提交的预约申请，支持按名称/预约人/状态查询、查看详情、受理与取消；后台不支持新增预约
- 包含页面：预约记录列表页、预约记录详情弹窗

### 资源中心门户子模块（前台展示端）

- 职责：面向 C 端用户展示后台已发布的资源（门户仅消费后台数据，不产生内容）；提供板块化浏览、搜索，以及按"是否收费 + 内容展示方式"分流的资源消费能力（免费/已购统一打开资源查看页、收费应用未购校验后引导去购买页、收费视频试看 30 秒后引导购买）
- 包含页面：资源中心门户
- 数据来源：状态=已发布的资源；按门户板块字段归入 AI建设者 / 课程教学 / 专题资源 / 教师成长 / 家校学思

## 五、核心业务流程

### 5.1 类目搭建主流程

1. 桂教通超管创建父频道 → 决定该父频道是否在资源中心展示 → 在父频道下按需新增子频道（最多两级）
2. 超管在子频道下创建一级分类 → 选择关联该子频道下已有的类目及类目条目 → 上架分类 → 应用端可获取分类；创建二级（子）分类时仅挂靠父分类，无需关联类目条目
3. 超管在"条目管理"中按子频道维护分类维度与维度条目 → 上架维度条目 → 应用端按配置动态渲染筛选视图

> 注：类目管理全流程仅桂教通超管可操作，机构人员不可见该模块。

### 5.2 上下架与应用端可见性契约

- "上架成功后才可在应用端获取到"
- "下架成功后应用端不可获取"
- 本设计仅约定契约点，具体推送/拉取机制由后端团队实现

### 5.3 删除保护流程

- 频道删除前：若被任意分类引用，禁止删除；若为父频道且下属存在子频道，禁止删除（需先删除子频道）
- 分类删除前：若处于"已上架"状态，禁止删除；下架后可删
- 分类维度删除前：若维度下存在维度条目，禁止删除，需先清空关联数据
- 维度条目删除前：若处于"已上架"状态，禁止删除，需先下架；若条目下仍存在子条目，禁止删除，需先删除全部子条目（R-DEL-07）
- 资源删除前：若处于"已发布"或"未审批"状态，禁止删除；仅"草稿"、"已驳回"、"未发布"状态可删

### 5.4 维度配置流程（条目管理）

1. 管理员在"分类管理"Tab 中新增分类维度（示例：学段、年级、学科），必选归属"所属频道"（级联选择父频道→子频道，选到子频道），可维护名称、排序（新增不含上架状态，提交后默认下架，编辑时可改上架状态）
2. 管理员在"分类条目管理"Tab 中筛选某个分类维度，新增该维度下的维度条目（示例：学段下的小学、初中、五四制），可维护名称、排序（新增不含上架状态，提交后默认未上架，编辑时可改上架状态）
3. 应用端拉取分类维度、维度条目两份配置，按维度动态渲染筛选行

### 5.5 资源管理主流程

#### 5.5.1 桂教通超管资源流程

1. 超管进入"资源列表"，可查看全量资源（含所有机构，含机构人员创建的草稿、未审批、已驳回等全部状态），按资源标题、所属频道、所属分类、状态筛选查询
2. 点击"新增资源"进入三步式表单：
   - 第一步（基本信息）：选择所属频道（级联父频道→子频道）、填写资源标题/简介、上传封面、按子频道过滤选择所属分类、按所属分类选择类目及类目条目、填写排序
   - 第二步（资源正文）：选择内容展示方式（富文本 / 文件·视频 / 应用和链接 / 链接），按方式填写对应内容，可维护文件列表（章节名称、文件上传、排序、删除）
   - 第三步（发布设置）：填写资源来源机构、资源作者
3. 提交动作有三种（提交与提交并发布均先对资源标题、简介、正文执行机器敏感词过滤 R-PUB-05）：
   - "保存草稿"：保存当前表单内容，资源状态置为 `草稿`，不执行敏感词过滤
   - "提交"：无论敏感词是否命中均可保存，资源状态置为 `未发布`；命中时页面顶部提示违规词，需修改通过后方可发布
   - "提交并发布"：仅当机器敏感词过滤通过时执行，资源状态置为 `已发布`，应用端可获取；命中违规词时该动作被拒绝，需修改后重试或先"提交"存为未发布
4. 列表中的资源可执行：发布（未发布→已发布，须已通过机器敏感词过滤）、下架（已发布→未发布，二次确认并取消推荐）、编辑、删除（仅"草稿"与"未发布"行展示编辑与删除按钮，已发布行不展示；需先下架后方可编辑或删除）、预览、设为推荐 / 取消推荐（仅已发布项，二次确认）
5. 勾选多行后可执行：批量发布（未发布项统一置为已发布）、批量下架（已发布项统一置为未发布并取消推荐）、批量推荐（仅对已发布项置为推荐，未发布项跳过）、批量取消推荐（推荐项统一置为否），均需二次确认并提示所选条数；未勾选任何行时按钮置灰（R-PUB-07、R-REC-01）

> 注：桂教通超管新增资源无需审批，流程与原有基本一致，仅新增"保存草稿"选项。

#### 5.5.2 机构人员资源流程

1. 机构人员进入"资源列表"，仅可查看本人创建的资源，按资源标题、所属频道、所属分类、状态筛选查询
2. 点击"新增资源"进入三步式表单（同超管表单结构，字段一致）
3. 提交动作有两种（提交前均先对资源标题、简介、正文执行机器敏感词过滤 R-PUB-05）：
   - "保存草稿"：保存当前表单内容，资源状态置为 `草稿`，不执行敏感词过滤
   - "提交"：敏感词过滤通过后，资源状态置为 `未审批`，同时生成（已存在则复用）该资源的审批记录到审批列表；命中违规词时该动作被拒绝，需修改后重试或先"保存草稿"
   - **不展示"提交并发布"按钮**
4. 列表中的资源按状态展示不同操作：
   - `草稿`：编辑、删除、预览
   - `未审批`：预览、撤回审核（不可编辑、不可删除；撤回后审批记录从审批列表移除，资源回到 `草稿`，可修改后重新提交）
   - `已驳回`：重新编辑、删除、预览（修改后提交，状态回到 `未审批`，复用同一条审批记录）
   - `未发布`：编辑、预览（为机构下架已发布资源后的状态，调整内容后可重新提交，状态回到 `未审批`，复用同一条审批记录）
   - `已发布`：预览、下架（仅本人创建的已发布资源；下架后状态置为 `未发布`，用于调整已审核资源内容，下架同步取消推荐）
5. 机构人员不展示：发布、设为推荐/取消推荐、批量发布/批量下架/批量推荐/批量取消推荐等操作按钮；"下架"仅对本人"已发布"资源展示

### 5.6 审批管理流程

1. 机构人员在"资源管理"中提交资源后，系统自动生成审批记录（审核状态=未审批），记录关联资源ID、机构名称、资源名称、所属频道、所属分类、提交人
2. 桂教通超管进入"审批管理 → 审批列表"，可查看全部审批记录；机构人员进入同一页面，仅可查看本机构发起的审批记录
3. 超管点击"审批"打开审批页，上方展示资源详细信息（只读），下方展示审批区域：
   - 审批结果（必填，单选）：通过 / 驳回
   - 审批意见（选填，最大 200 字符）
4. 超管提交审批后：
   - 审批通过：审批记录状态→`审批通过`，关联资源状态自动变为 `已发布`，应用端可获取
   - 审批驳回：审批记录状态→`已驳回`，关联资源状态变为 `已驳回`，机构人员可编辑修改后重新提交
5. 机构人员重新提交已驳回的资源后，复用同一条审批记录（不新建），资源状态回到 `未审批`，本轮审批明细追加至审批历史
6. 超管可在资源列表中手动下架已发布的资源（包括审批通过后自动发布的），下架后资源状态→`未发布`，超管可直接重新发布，不需要再走审批
7. 机构人员对本人创建的已发布资源需要调整内容时，可在资源列表执行"下架"（状态→`未发布`，同步取消推荐），随后编辑并重新"提交"：资源状态→`未审批` 并复用同一条审批记录，进入新一轮审批（通过→重新 `已发布`，驳回→`已驳回`，可再次编辑提交）
8. 机构人员可对本人"未审批"资源执行"撤回审核"：撤回后该资源的审批记录整条从审批列表移除（含历次审批明细），资源状态回到`草稿`；如需再次审批，重新编辑并"提交"即重新生成审批记录

### 5.7 硬件与服务管理主流程

1. 管理员进入"智慧硬件与服务"，可按名称（模糊）、频道（级联父频道→子频道）、分类（按频道过滤）、状态（未发布/已发布/已下架）筛选查询
2. 点击"新增"打开"硬件/服务新增/编辑页"：填写名称、选择类型（智慧硬件 / 定制服务）、选择所属频道（级联到子频道）、按频道选择所属分类、填写排序、填写背景色与字体颜色（十六进制色值，如 #ffffff）、填写简介（50 字符以内）与详细介绍（200 字符以内）、上传详细介绍图片（至少 1 张，单张 ≤10MB）、可选上传附件（最多 5 个，单个 ≤20MB）；保存后状态为 `未发布` 并返回列表
3. 编辑动作复用同一页面并回填当前值，保存即生效（不改变发布状态）；点击"取消"或"返回列表"放弃修改回到列表页
4. 列表行可执行：发布（未发布/已下架→已发布，二次确认）、下架（已发布→已下架，二次确认）、编辑、删除（已发布不可删，需先下架）
5. 勾选多行后可执行：批量发布（所选项统一置为已发布，已发布项保持不变）、批量下架（所选项统一置为已下架），均需二次确认
6. 应用端用户对已发布的硬件/服务提交预约 → 预约数据进入"预约记录"，管理员可按名称、预约人、状态查询，查看详情后执行受理（待处理→已受理）或取消（待处理/已受理→已取消）

## 九、规则与状态定义

### 9.1 字段校验规则

| 规则编号 | 适用字段 | 规则 |
|---|---|---|
| R-CH-01 | 频道名称、分类名称、维度名称、维度条目名称 | 必填，最长 20 字符 |
| R-CH-02 | 分类编码 | 必填，不允许中文，最长 10 字符 |
| R-CH-03 | 频道图标 | 必填，尺寸 68×68，大小 ≤100KB |
| R-CH-05 | 频道图片 | 父频道（父频道为空）必填，大小 ≤300KB；子频道（父频道非空）选填，大小 ≤5M |
| R-CH-06 | 频道描述、分类描述 | 选填，最长 200 字符 |
| R-CH-07 | 排序、维度排序、条目排序 | 必填，非负整数 |
| R-CH-10 | 资源标题 | 必填，最长 30 字符 |
| R-CH-11 | 资源简介 | 选填，最长 200 字符 |
| R-CH-12 | 资源封面 | 选填，格式 .jpg/.jpeg/.png，尺寸 245×143，大小 ≤3MB |
| R-CH-13 | 资源来源机构 | 必填，最长 30 字符 |
| R-CH-14 | 资源作者 | 选填，最长 30 字符 |
| R-CH-15 | 移动端链接、PC端链接 | 内容展示方式=链接时必填；=应用和链接时选填；最长 200 字符 |
| R-CH-16 | 内容详情 | 内容展示方式=富文本时必填 |
| R-CH-17 | 资源文件 | 格式限 .mp4/.doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf；文档 ≤50MB、视频 ≤500MB；单资源最多 50 个 |
| R-CH-18 | 章节名称 | 是否开启小节=是时必填，否则不显示；最长 20 字符 |
| R-CH-19 | 频道·父频道 | 层级最多两级：父频道的"父频道"字段为空；子频道的"父频道"字段必须指向一个已存在且"父频道"为空的父频道；子频道不允许再被选作父频道 |
| R-CH-20 | 分类·所属频道 | 必填；级联选择时必须选到二级（子频道）；仅存二级频道ID |
| R-CH-21 | 分类·类目及类目条目 | 仅一级/顶级分类展示；若该子频道（所属频道）下存在已上架类目条目则展示该字段且为必填，须至少完成勾选一项，为空提示"请选择类目及类目条目"；勾选条目后若该条目下存在已上架子条目，展示对应子条目并可继续勾选（仅展示已上架的子条目；未勾选的条目不展示其子条目）；若该子频道下无任何类目条目则不展示该字段（标签与勾选区均不出现）；二级/子分类不展示此字段；所属频道通过单个级联输入框选择（父频道→子频道） |
| R-CH-22 | 分类维度·所属频道 | 必填；级联选择时必须选到二级（子频道）；仅存二级频道ID |
| R-CH-23 | 资源·类目及类目条目展示与只读 | 展示所属分类所在子频道下全部类目及类目条目；其中该分类已关联的类目条目默认勾选且只读（不可取消），其余条目用户可自由勾选/取消；未选所属分类时不展示 |
| R-CH-24 | 硬件/服务·名称、类型 | 名称必填、最长 30 字符；类型必填，枚举"智慧硬件 / 定制服务"，默认"智慧硬件" |
| R-CH-25 | 硬件/服务·所属频道、所属分类、排序 | 所属频道必填，级联必须选到二级（子频道）；所属分类按所属频道过滤，该频道下存在分类时必填、无分类时非必填；排序必填、非负整数 |
| R-CH-26 | 硬件/服务·背景色、字体颜色 | 均必填；格式必须为十六进制色值 `#RRGGBB`（兼容 `#RGB`），如 `#ffffff`；格式不合法时阻断保存并提示 |
| R-CH-27 | 硬件/服务·简介、详细介绍 | 简介必填、最长 50 字符；详细介绍必填、最长 200 字符 |
| R-CH-28 | 硬件/服务·详细介绍图片、附件 | 详细介绍图片必填，至少 1 张，支持一次上传多张，格式 .jpg/.jpeg/.png，单张 ≤10MB；附件非必填，最多 5 个，单个 ≤20MB，格式 .doc/.docx/.xls/.xlsx/.ppt/.pptx/.pdf |
| R-CH-29 | 预约记录·预约人、联系方式、预约时间 | 均由应用端用户提交时必填；联系方式为手机号格式，列表脱敏展示 |
| R-CH-31 | 资源·收费方式与购买引导 | 收费方式必填，单选"免费 / 收费"，默认"免费"（内容展示方式="链接"时不展示该字段）；=收费且内容展示方式≠"应用和链接"、≠"链接"时，额外展示购买引导字段；=收费且内容展示方式="应用和链接"时不重复展示购买引导字段，收费方式以所选应用自带收费方式为准；付费方式、价格仍不采集 |
| R-CH-32 | 资源·权益与购买链接必填性 | 收费方式=收费时展示"权益"（数量 + 单位"天 / 次"，默认"天"），不受内容展示方式限制（内容展示方式="应用和链接"且收费时同样展示）；权益为选填，留空表示不限制权益，一旦填写数量则须为 >0 的数字（支持小数点），否则阻断提交并提示；内容展示方式≠"应用和链接"时另需"应用选择"必填，"PC端链接 / 移动端链接"改为选填，未填写时应用端不给出购买跳转入口 |
| R-CH-33 | 资源·链接板式不采集收费信息 | 内容展示方式="链接"时，资源正文不展示"收费方式""权益"，也不展示购买引导组的"应用选择 / PC端链接 / 移动端链接"；该资源固定按"收费方式=免费"保存，权益与购买引导字段一并置空，应用端不做收费标识与购买引导 |
| R-CH-30 | 分类·分类图标、分类封面、按钮文字 | 三者均为选填：分类图标（单张，.jpg/.jpeg/.png，≤2MB）、分类封面（单张，.jpg/.jpeg/.png，≤5MB）、按钮文字（最长 10 字符）；空值允许保存，上传后仍按上述大小/格式校验；一级与子分类均适用 |

### 9.2 排序规则

- 同层级按"排序"字段升序展示；排序值相同时，按"修改时间"倒序展示（后修改的靠前）
- 该规则适用于频道列表、分类树同层、分类维度列表、维度条目同维度、智慧硬件与服务列表
- 预约记录列表按"创建时间"倒序展示（最新提交的预约在前）

### 9.6 状态机

#### 分类状态机

- 状态集合：`未上架`、`已上架`
- 迁移：
  - `未上架 → 已上架`：管理员触发"上架"动作 + 二次确认；系统写入上架状态并通知应用端
  - `已上架 → 未上架`：管理员触发"下架"动作 + 二次确认；系统写入未上架状态并通知应用端
- 限制：`已上架` 状态下禁止删除

#### 维度条目状态机

- 状态集合：`未上架`、`已上架`
- 迁移规则同分类
- 限制：`已上架` 状态下禁止删除

#### 分类维度上架状态机

- 状态集合：`上架`、`下架`
- 初始：新增分类维度提交后默认进入`下架`（新增弹窗不展示上架状态字段）
- 迁移：
  - `上架 → 下架`：管理员触发"下架"动作；应用端不再渲染该维度，但配置保留
  - `下架 → 上架`：管理员触发"上架"动作；应用端恢复渲染该维度
- 限制：维度下存在维度条目时禁止删除

#### 资源状态机

- 状态集合：`草稿`、`未审批`、`已驳回`、`未发布`、`已发布`
- 初始：新增资源"保存草稿"进入 `草稿`

##### 桂教通超管路径

- 迁移：
  - `草稿 → 未发布`：超管触发"提交"动作（不受敏感词过滤限制，但违规资源不可继续发布）
  - `草稿 → 已发布`：超管触发"提交并发布"动作；须机器敏感词过滤通过（R-PUB-05），命中时拒绝
  - `未发布 → 已发布`：超管触发列表"发布"或"批量发布"动作；前置约束：机器审核结果必须为`通过`
  - `已发布 → 未发布`：超管触发"下架"或"批量下架"动作 + 二次确认；同步将"是否推荐"置为`否`
- 限制：`已发布` 状态下禁止删除和编辑；`草稿`与`未发布`状态下可编辑和删除

##### 机构人员路径

- 迁移：
  - `草稿 → 未审批`：机构人员触发"提交"动作；须机器敏感词过滤通过（R-PUB-05），通过后自动生成该资源的审批记录（同一资源仅一条，已存在则复用）
  - `未审批 → 已发布`：超管审批通过后系统自动迁移；应用端可获取
  - `未审批 → 已驳回`：超管审批驳回后系统自动迁移
  - `已驳回 → 未审批`：机构人员修改后重新"提交"；须再次通过机器敏感词过滤；复用同一条审批记录（不新增），状态重置为`未审批`
  - `已发布 → 未发布`：超管或机构人员触发"下架"+ 二次确认；机构人员仅限本人创建的已发布资源，多用于调整已审核资源内容；同步将`是否推荐`置为`否`
  - `未发布 → 未审批`：机构人员对本人`未发布`资源（下架后的已审核资源）编辑后"提交"；须机器敏感词过滤通过，复用同一条审批记录并进入新一轮审批
  - `未发布 → 已发布`：仅超管可重新发布（机构人员不可操作）
  - `未审批 → 草稿`：机构人员触发"撤回审核"+ 二次确认；同步移除该资源的审批记录（含历次明细），可修改后重新提交（重新生成审批记录）
- 限制：`未审批`状态下禁止编辑和删除（仅可撤回审核）；`已发布`状态下机构人员仅可预览与下架；`草稿`、`已驳回`与（本人）`未发布`状态下可编辑；`草稿`与`已驳回`状态下可删除
- 推荐：`是否推荐` 仅在 `已发布` 状态下可由超管置为`是`（单条或批量，均需二次确认）；下架后自动回到`否`（R-REC-01）

#### 审批记录状态机

- 状态集合：`未审批`、`审批通过`、`已驳回`
- 初始：机构人员提交资源时自动生成，进入 `未审批`
- 迁移：
  - `未审批 → 审批通过`：桂教通超管在审批页选择"通过"并提交；系统同步将关联资源状态置为`已发布`
  - `未审批 → 已驳回`：桂教通超管在审批页选择"驳回"并提交；系统同步将关联资源状态置为`已驳回`
  - `已驳回 → 未审批`：机构人员修改已驳回的资源后重新提交；复用该资源同一条审批记录（不新增记录），审核状态重置为`未审批`，历次审批明细保留在审批历史中
  - `未审批 → 已移除`：机构人员在资源列表"撤回审核"后，该资源的审批记录整条从审批列表移除（含历次审批明细），资源回到`草稿`；再次提交时重新生成审批记录
- 限制：审批记录不提供单独删除入口（仅随"撤回审核"整条移除）；仅桂教通超管可执行审批操作；**同一资源仅生成一条审批记录**（以资源 ID 唯一），驳回后重新提交仍复用该记录；每次审批结果、审批意见、审批人、审批时间追加到审批历史明细，只增不改，按轮次正序展示（R-APR-01~05）

#### 智慧硬件与服务状态机

- 状态集合：`未发布`、`已发布`、`已下架`
- 初始：新增保存后进入 `未发布`
- 迁移：
  - `未发布 → 已发布`：管理员触发"发布"或"批量发布"动作 + 二次确认；应用端可获取并可预约
  - `已下架 → 已发布`：管理员触发"发布"或"批量发布"动作 + 二次确认
  - `已发布 → 已下架`：管理员触发"下架"或"批量下架"动作 + 二次确认；应用端不再展示，已产生的预约记录保留
- 限制：`已发布` 状态下禁止删除；编辑保存不改变状态

#### 预约记录状态机

- 状态集合：`待处理`、`已受理`、`已完成`、`已取消`
- 初始：应用端提交后进入 `待处理`
- 迁移：
  - `待处理 → 已受理`：管理员触发"受理"动作 + 二次确认
  - `待处理 / 已受理 → 已取消`：管理员触发"取消"动作 + 二次确认
  - `已受理 → 已完成`：线下服务完成后由系统或管理员标记
- 限制：预约记录不可删除

#### 频道

- 无上下架状态机；仅有"是否在资源中心展示"开关字段（`是 / 否`），由管理员在新增/编辑时直接维护

### 9.7 后台人员配置规则

- R-CFG-01 同一人员（所属机构 + 手机号）仅可配置一条：保存时校验，重复则阻断保存并提示"该人员已在配置列表"
- R-CFG-02 姓名与手机号由人员选择带出：先选所属机构（第一行，可搜索下拉），再在该机构人员中搜索选择姓名（选项展示"姓名/手机尾号4位(部门)"并带姓氏头像），选中后自动带出手机号（必填、只读）与部门；切换机构后清空已选人员
- R-CFG-03 状态不落表单：新增提交后状态固定为"启用"；列表内可启用/停用，停用后人员立即失去资源后台访问能力，启用后恢复
- R-CFG-04 登录权限判定：人员登录后系统按后台人员配置判断是否有权限进入资源后台；配置内人员菜单权限=资源列表+审批列表，数据范围=仅本人创建的资源与审批数据；未配置人员不可进入后台
- R-CFG-05 可配置频道至少勾选 1 个，决定该人员在频道相关页面（频道管理、分类管理、条目管理、资源按频道筛选等）可见与可操作的数据范围
- R-CFG-06 删除仅做二次确认，删除后该人员立即失去后台访问能力；人员相关操作留痕保留

### 9.8 资源批量导入与视频附件规则

- R-RES-11 内容展示方式选项固定为：富文本 / 文件·视频 / 应用和链接 / 链接 / 视频，按此顺序排列，"视频"在最后
- R-RES-12 内容展示方式=视频时，附件仅支持所有视频格式（.mp4/.avi/.mov/.wmv/.flv/.mkv 等），单个文件大小 ≤1GB；上传时校验格式与大小，不符合则阻断并提示
- R-RES-13 批量导入（P10，全角色）：下载导入模板后选择 .xlsx 文件导入，单次最多 100 条，仅创建资源基本内容；桂教通超管导入的资源状态=未发布，机构人员导入的资源状态=草稿（提交审批后走正常审批流）；内容展示方式=视频/文件·视频的资源导入后需进入编辑页手动上传对应附件，附件未上传不可发布
- R-RES-14 批量导入按模板字段逐行校验：资源标题必填、所属频道须在当前人员可配置频道范围内、所属分类须属于该频道下的一级分类、内容展示方式须为合法枚举（R-RES-11）；校验失败的行整行跳过、不入库，并在「导入历史」中记录错误原因
- R-RES-15 批量导入模板按人员配置生成：模板「所属频道」枚举仅限当前登录人员（配置管理）可配置的频道，对应「所属分类」枚举为该频道下的一级分类；桂教通超管模板含全部频道；机构人员模板仅含其被授权的频道与分类
- R-RES-16 导入历史（P10，全角色）：记录每次导入的时间、文件名、总条数、成功/失败条数、状态与逐行错误明细；「导出源文件」导出含「导入错误信息」列的源文件（失败行末尾追加错误原因）；超管可见全量历史，机构人员仅见本人所属机构历史
- R-RES-17 资源列表表格交互：操作列固定在表格最右侧（sticky），其余列横向滚动时不随之移动；其余列可横向滚动/拖动查看，纵向由页面滚动承担；操作列随内容自适应宽度并保持不换行
- R-RES-18 撤回审核：仅机构人员、仅本人"未审批"资源可撤回，须二次确认；撤回后该资源的审批记录整条从审批列表移除（含历次审批明细），资源状态回到`草稿`，可修改后重新提交；撤回不保留审批历史，重新提交时重新生成审批记录

### 9.9 审批记录与审批历史规则

- R-APR-01 审批记录唯一性：同一资源仅生成一条审批记录（以资源 ID 唯一）；驳回后重新提交不再新增记录，复用原记录并把审核状态重置为`未审批`
- R-APR-02 审批历史明细：每次审批追加一条明细，包含审批结果（通过/驳回）、审批意见、审批人、审批时间（附本轮提交时间）；明细只增不改，P31 审批页按轮次正序展示该资源的全部审批轮次
- R-APR-03 审批页呈现：资源详情以 form 表单（3 列布局，label 后加冒号）只读呈现，不展示排序、审核状态、更新时间、提交时间；含「资源正文内容」与「资源附件」（非视频类）区块；页面自上而下分「资源详情 / 审批历史 / 审批信息（仅审批模式）」三个可折叠区块，默认全部展开、点击标题切换；审批历史列表下方固定分页组件（5 条/页，含总条数），无历史时提示"暂无审批历史"
- R-APR-04 审批页导航：页面不展示页内标题与"返回列表"按钮，返回列表统一由面包屑「审批管理 / 审批列表 / 资源审批（审批详情）」完成
- R-APR-05 审批页正文渲染：按资源内容展示方式分流（视频类形态与资源预览 P15 的播放器 + 附件列表一致）——`富文本`→富文本详情（标题+段落+列表，限高滚动）；`文件·视频`/`视频`→左侧视频播放器+右侧附件文件列表（含类型图标）；`应用和链接`/`链接`等非媒体类方式→文本方式呈现正文内容（应用和链接额外展示应用名称与 PC/移动端链接）

## 十、权限定义

### 10.1 页面级权限

| 页面 | 桂教通超管 | 机构人员 |
|---|---|---|
| P01 频道列表页 | 可见、可操作 | 不可见 |
| P02 频道新增/编辑页 | 可见、可操作 | 不可见 |
| P03 分类列表页 | 可见、可操作 | 不可见 |
| P04 分类新增/编辑页 | 可见、可操作 | 不可见 |
| P07 条目管理·分类管理 Tab | 可见、可操作 | 不可见 |
| P08 条目管理·分类条目管理 Tab | 可见、可操作 | 不可见 |
| P10 资源列表页 | 可见、全量数据、全操作 | 可见、仅本人创建数据、受限操作 |
| P11 资源新增/编辑页 | 可见、含"提交并发布"按钮 | 可见、不含"提交并发布"按钮 |
| P15 资源预览页 | 可见（仅本人可预览范围内的已发布资源） | 可见（仅本人创建、已发布资源） |
| P12 资源中心门户 | 可见（前台，不受后台角色约束） | 可见（前台，不受后台角色约束） |
| P13 应用购买页 | 可见（前台） | 可见（前台） |
| P14 资源查看页 | 可见（前台） | 可见（前台） |
| P20 智慧硬件与服务列表页 | 可见、可操作 | 不可见 |
| P21 预约记录列表页 | 可见、可操作 | 不可见 |
| P22 硬件/服务新增/编辑页 | 可见、可操作 | 不可见 |
| P30 审批列表页 | 可见、全量数据、可审批 | 可见、仅本人发起数据、仅查看 |
| P31 审批页/查看页 | 可见、审批模式（可操作审批结果与意见） | 可见、查看模式（不展示审批操作区） |
| P40 配置列表页 | 可见、可操作 | 不可见 |
| P41 配置新增/编辑页 | 可见、可操作 | 不可见 |

### 10.2 操作级权限

| 操作 | 桂教通超管 | 机构人员 |
|---|---|---|
| 新增资源 | 允许 | 允许（本人创建） |
| 编辑资源 | 允许（草稿/未发布状态） | 允许（草稿/已驳回/未发布状态、本人创建；已驳回行展示"重新编辑"） |
| 撤回审核 | 不允许（无该操作） | 允许（仅本人"未审批"资源；撤回后审批记录移除、资源→草稿） |
| 删除资源 | 允许（草稿/未发布状态） | 允许（仅草稿/已驳回状态、本人创建） |
| 保存草稿 | 允许 | 允许 |
| 提交资源 | 允许（→未发布） | 允许（→未审批，生成审批记录） |
| 提交并发布 | 允许（→已发布） | 不允许（按钮不展示） |
| 发布资源 | 允许 | 不允许 |
| 下架资源 | 允许 | 允许（仅本人创建、已发布状态；用于调整内容后重新提交审批） |
| 设为推荐/取消推荐 | 允许 | 不允许 |
| 批量发布/下架/推荐/取消推荐 | 允许 | 不允许 |
| 批量导入资源 | 允许（导入后状态=未发布） | 允许（导入后状态=草稿；视频/文件·视频类需手动上传附件后才能发布） |
| 查看导入历史 | 允许（全量） | 允许（仅本人所属机构） |
| 预览资源 | 允许 | 允许（本人创建、已发布） |
| 审批资源 | 允许 | 不允许 |
| 查看审批记录 | 允许（全量） | 允许（仅本人发起） |
| 类目管理全部操作 | 允许 | 不允许（菜单不可见） |
| 硬件与服务管理全部操作 | 允许 | 不允许（菜单不可见） |
| 预约记录管理 | 允许 | 不允许（菜单不可见） |
| 配置后台人员（新增/编辑/删除） | 允许 | 不允许（菜单不可见） |
| 启用/停用后台人员 | 允许（内置超管账号除外） | 不允许（菜单不可见） |

### 10.3 字段级权限

| 字段 | 桂教通超管 | 机构人员 |
|---|---|---|
| 所属机构 | 可读（系统写入） | 可读（系统写入，不可修改） |
| 创建人 | 可读（系统写入） | 可读（系统写入，不可修改） |
| 审批结果、审批意见 | 可读可写（审批时） | 可读（查看模式） |
| 其余"系统生成"字段 | 可读、不可编辑 | 可读、不可编辑 |
| 其余用户填写字段 | 可读可写 | 可读可写（仅本机构资源） |

### 10.4 数据范围权限

| 数据对象 | 桂教通超管 | 机构人员 |
|---|---|---|
| 资源 | 全量（所有机构） | 仅本人创建的（R-CFG-04） |
| 审批记录 | 全量（所有机构） | 仅本人发起的（R-CFG-04） |
| 类目（频道/分类/条目） | 全量 | 不可见 |
| 硬件与服务 | 全量 | 不可见 |
| 后台人员配置 | 全量 | 不可见 |
| 预约记录 | 全量 | 不可见 |
